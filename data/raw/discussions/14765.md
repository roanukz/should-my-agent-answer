### Description

Steps to reproduce:

- Put the example code into a main.py file.
- Create a virtual environment and install fastapi.
- Run it with "fastapi run main.py --workers 3".
- Try to stop it with Ctrl+C.

If you run it with 1 or 2 workers, it can be stopped without any issue. But if you run it with 3 or more workers you can't stop it.

I also have formatting issues in CLI output (wrong indentation).

## Accepted answer by YuriiMotov (MEMBER)

The issue was in `rich-toolkit` dependency and it was fixed by @patrick91 in `0.17.2`: https://github.com/patrick91/rich-toolkit/releases/tag/0.17.2

So, upgrade `rich-toolkit` to `>=0.17.2` and it should work!
