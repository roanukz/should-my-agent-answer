### Description

The resulting dd is invalid as itemSchema is not a valid property on OpenAPI 3.1 MediaType

paths:
  /jsonl:
    get:
      description: https://fastapi.tiangolo.com/tutorial/stream-json-lines/#use-cases
      operationId: jsonl
      responses:
        '200':
          content:
            application/jsonl:
              itemSchema:
                $ref: '#/components/schemas/Item'
          description: Successful Response
      summary: Jsonl

## Accepted answer by YuriiMotov (MEMBER)

Thanks for reporting!

We are aware of this. We are planning to update OpenAPI schema version to `3.2`, but there are several things to be done before this. So, we will fix this at some point.
If it causes problems for you, as a workaround you can use the approach described in docs (https://fastapi.tiangolo.com/how-to/extending-openapi/) to modify the schema and pass `openapi_version="3.2.0"` to `get_openapi`
