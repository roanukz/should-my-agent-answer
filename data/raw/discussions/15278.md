## Accepted answer by DoctorJohn (MEMBER)

@NouhJama, we managed to reproduce the issue. It's essentially happening when WSL is used, and the app's source code is stored in the Windows file system (i.e., in Linux, your code is mounted somewhere under the `/mnt` path).

We're working on a fix for this! A temporary workaround would be to move your code anywhere else inside Linux except for the `/mnt` directory (somewhere in `/home/yourusername` would be a good choice).

UPDATE: A fix has been released. Make sure you update your project dependency to get the latest `fastapi-cloud-cli` version
