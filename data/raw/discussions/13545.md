## Accepted answer by luzzodev (CONTRIBUTOR)

Hello @gurobokum,

> What is the reason to have HTTPBase and derived classes call method async?

Fastapi is an asynchronous framework, all subclasses of `HTTPBase ` can be used as dependency and for this reason they are async. Each not async dependency is executed in a separated thread to avoid blocking the main loop, so make it sync, would be only inefficient.

About your case: since logfire for fastapi is based on [OpenTelemetry FastAPI Instrumentation](https://opentelemetry-python-contrib.readthedocs.io/en/latest/instrumentation/fastapi/fastapi.html) would be better to attach the user info to the request or a span and read them from there instead of reprocessing the header twice.
