### Example Code

```python
@app.middleware("http")
async def tenant_middleware(request: Request, call_next):
    wsgi_environ = request.scope.get("wsgi_environ")
    path_info = wsgi_environ["PATH_INFO"]
    path_info_parts = path_info.lstrip("/").split("/")
    TENANT_PATH_IDENTIFIER = "tenant"
    if (
        len(path_info_parts) >= 2
        and path_info_parts[0].lower() == TENANT_PATH_IDENTIFIER
    ):
        tenant_id = path_info_parts[1]
        new_path_info = "/" + "/".join(path_info_parts[2:])
        wsgi_environ["PATH_INFO"] = new_path_info
        _logger.debug(f"Rewrite path {path_info} => {new_path_info}, {tenant_id=}")
    else:
        tenant_id = request.headers.get("X-Tenant-Id")
    if not tenant_id:
        tenant_id = "default"  # Use a default tenant if none is provided
    request.state.tenant_id = tenant_id
    response = await call_next(request)
    return response
```


### Description

I try to implement Tenant support by passing either 
- a X-Tenant-Id header
- or prepend `/tenant/ID/` to the request URL

The latter does not seem to work. 
Even if I remove the prefix from `PATH_INFO` the router probably ignores that and responds with 'Not found'

So my question is either 
- how would I remove a prefix from the request URL, so that the router picks up from there?
- Is there a better aproach to address this problem

## Accepted answer by alv2017 (CONTRIBUTOR)

In the meantime, while waiting for better solutions: :smile:

Please note regarding the @app.middleware decorator:

        """
        We no longer document this decorator style API, and its usage is discouraged.
        Instead you should use the following approach:

        >>> middleware = [Middleware(...), ...]
        >>> app = Starlette(middleware=middleware)
        """

The recommended approach is to use class-based middleware. This is example from Starlette:

```python
from starlette.applications import Starlette
from starlette.middleware import Middleware
from starlette.middleware.base import BaseHTTPMiddleware


class CustomHeaderMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        response = await call_next(request)
        response.headers['Custom'] = 'Example'
        return response

routes = ...

middleware = [
    Middleware(CustomHeaderMiddleware)
]

app = Starlette(routes=routes, middleware=middleware)
```

The middleware used in FastAPI is coming from Starlette, and Starlette has much more extensive documentation on middlewares: https://www.starlette.io/middleware

For low level operations, like manipulating ASGI scopes, refer the documentation of the application server (uvicorn, or whatever you are using).
