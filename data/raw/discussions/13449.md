## Accepted answer by YuriiMotov (MEMBER)

I think the best way is not to use `Request.state` directly in endpoint functions, but create dependencies to access variables you need.
Then you can just override those dependencies in a usual way
```
from fastapi import Depends, APIRouter, Request, FastAPI

app = FastAPI()

def some_dependency(request: Request):
    request.state.some_object = "state changed in dependency"

router = APIRouter(
    dependencies=[Depends(some_dependency)],
)

async def get_some_object(req: Request):
    return req.state.some_object

@router.get("/")
async def some_get(some_object: Any = Depends(get_some_object)):
    return some_object

app.include_router(router)
```
