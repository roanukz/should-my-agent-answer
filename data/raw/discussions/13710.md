### Example Code

```python
def get_token():
    # tokens have a 2 hour lifetime
    import uuid

    LOGGER.warning("new token") # prints every request
    return str(uuid.uuid4())


def get_connection(token: Annotated[str, Depends(get_token]):
    import requests

    LOGGER.warning("new session %s", token) # prints every request with different token
    with requests.Session() as s:
        yield s


router = APIRouter(prefix="/")


@router.get(path="/check2")
def check_deps_2(r_session=Depends(get_connection)):
    return r_session.get("http://jsonplaceholder.typicode.com/posts/2").json()


@router.get(path="/check")
def check_deps_1(r_session=Depends(get_connection)):
    return r_session.get("http://jsonplaceholder.typicode.com/posts/1").json()
```


### Description

Hello, 

my TLDR is I want to query an external api that requires token auth without refreshing my token every call. I wanted to know best practices for this if any?

I would like to make an External HTTP call that relies on a token -- this is a toy example of course, I noticed when I use dependencies I get a new token every time and a new session every time. 

My expectations that at least immediate subsequent calls are cached and not recalled. In the example I provided each request has a new token (less than ideal), and a a new session (that is okay). I wanted to avoid flooding my lifetime dependencies with any external connection but I do not want to have to make new tokens for any type of outgoing request each time. 

I have a feeling I am doing something wrong or its as simple as making an LRU cache with TTL for `get_tokens()`

What I would like to know is 
1. Best practices with external HTTP calls and if there is a recommendation to use session (request) or AsyncClient (httpx)
    - Is it better to initialize these in the lifetime dep or in path dependencies
2. Best practices for cacheing dependencies -- I know if multiple dependencies call a similar sub dependency they are [cached](https://fastapi.tiangolo.com/tutorial/dependencies/sub-dependencies/#using-the-same-dependency-multiple-times) but are there recommendations or "gotchas" to cacheing a dep yourself?

## Accepted answer by YuriiMotov (MEMBER)

Common approach will be to use Redis cache (not sure you need it in this particular case).

But, if you only need to cache this dependency in one worker instance and you don't want to add Redis, you can use `cachetools` lib:

Install `cachetools`:

```
pip install cachetools
```

Use it:
```Python
from time import sleep

from cachetools import TTLCache, cached

cache = TTLCache(maxsize=100, ttl=2)  # TTL = 2 sec

@cached(cache)
def get_token():
    # tokens have a 2 hour lifetime
    import uuid
    LOGGER.warning("new token") # prints every request
    return str(uuid.uuid4())


a = get_token()

b = get_token()

sleep(3)

c = get_token()


assert a == b
assert a != c

```
