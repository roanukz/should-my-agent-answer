# Why does pip install fastapi include a SKILL.md under .agents/skills/?

Discussion #15843 · 2026-06-25T17:40:22Z · https://github.com/fastapi/fastapi/discussions/15843

## Question

The `SKILL.md` file is installed within the `site_packages` directory (specifically, under `fastapi/.agents/skills/fastapi`) when the `fastapi` package is installed using pip.

What is the purpose of this file? How is it consumed by users of the package? What is its intended use?

## Accepted answer by YuriiMotov (MEMBER)

Open project that uses FastAPI as dependency, and run `uvx library-skills`. It will suggest installing this skill. And it will be always up to date with the version of FastAPI installed. 

See https://library-skills.io/
