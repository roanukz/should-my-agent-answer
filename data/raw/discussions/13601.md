## Accepted answer by alv2017 (CONTRIBUTOR)

> so if the user disconnected(or i think it should be any websocket error?), then it results in the after sending 'websocket.close' or response already completed. error, am i getting it right?

Not quite. :smiley:

You are getting this particular error (`after sending 'websocket.close' or response already completed`) when the following conditions hold:
1) The client disconnected
2) and then you called `websocket.close()` method`

Please also note that `WebSocketDisconnect` is the only exception classed handled by Starlette websockets module.

If you want to know more just dig into the `websockets.py` Starlette module, and start observing:
- `websocket.client_state`
- `websocket.application_state`
