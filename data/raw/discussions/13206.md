### Description

When using `Depends`, the fields are [added at the end](https://stackoverflow.com/questions/77719635/how-order-fields-in-fastapi-swaggerui). I would like to be able to control the order by where I place `document_params: str = Depends(validate_document_params)` in the endpoint.

## Accepted answer by YuriiMotov (MEMBER)

As far as I know you can not specify the order of parameters in openapi schema by changing their order in function definition..

But you can modify openapi schema:

```
from typing import cast
from fastapi import Depends, FastAPI, Form
from fastapi.openapi.utils import get_openapi

app = FastAPI()


def validate_document_params(
    document_id: str = Form(),
    env_id: str = Form(),
):
    return "test"


@app.get("/test")
async def test(
    document_params: str = Depends(validate_document_params), model_name: str = Form()
):
    return {document_params, model_name}


FIRST_ORDER_FIELDS = {"document_id", "env_id"}


def custom_openapi():
    if app.openapi_schema:
        return app.openapi_schema
    openapi_schema = get_openapi(
        title=app.title,
        version=app.version,
        summary=app.summary,
        description=app.description,
        routes=app.routes,
    )

    for schema in cast(dict, openapi_schema["components"]["schemas"]).values():
        properties: dict = schema["properties"]
        schema["properties"] = dict(
            sorted(
                properties.items(),
                key=lambda x: x[0] in FIRST_ORDER_FIELDS,
                reverse=True,
            ),
        )

    app.openapi_schema = openapi_schema
    return app.openapi_schema

app.openapi = custom_openapi
```
