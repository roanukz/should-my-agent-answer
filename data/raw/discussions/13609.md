## Accepted answer by luzzodev (CONTRIBUTOR)

Hello @zowi-net,
Python 3.14 is still under development and is not officially supported by FastAPI or TensorFlow (currently supporting Python 3.9–3.12). The latest Python version officially supported by FastAPI is Python 3.13, introduced in FastAPI version 0.115.8.
