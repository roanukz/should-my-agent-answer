from enum import Enum

from fastapi import FastAPI, Path


app = FastAPI()

    a = "A"

### Description

I'm brand new to FastAPI and whilst going through the tutorial I got to the section about using predefined values for path parameters. https://fastapi.tiangolo.com/tutorial/path-params/#predefined-values

The example uses Enum, and I just wanted to know if there is any reason to use this instead of typing.Literal in basic cases?

I've included an example showing the two ways to type hint (enum vs. Literal) and the resulting Swagger page seems the same. I know that Enum would let me do `path_type is PathParamOptions.a` for equivalent checks, but other then that is there any major difference that I'm missing?

## Accepted answer by Codeslayer27 (NONE)

For **simple type hinting literal works well** for more complex scenarios Enum provides more flexibility for example adding metadata to Enum values also, can provide more complex logic around enumeration. Performance differences are negligible.
