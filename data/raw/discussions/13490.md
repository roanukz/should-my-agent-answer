### Example Code

```python
import uvicorn
import nest_asyncio
nest_asyncio.apply()

from fastapi import FastAPI, Depends
from pydantic import BaseModel, Field
from typing_extensions import Annotated, Literal

app = FastAPI()


class FilterParams(BaseModel):
    limit: int = Field(100, gt=0, le=100)
    offset: int = Field(0, ge=0)
    order_by: Literal["created_at", "updated_at"] = "created_at"
    tags: list[str] = []


@app.get("/items/")
async def read_items(filter_query:FilterParams=Depends()):
    return filter_query

if __name__ == "__main__":
    uvicorn.run(app , host="0.0.0.0", port=8000)
```


### Description

in the documentation part of "Query Parameter Models" , it has been mentioned to use "Query", but Query work with primitive types and since we will use Pydantic Base Model , we have to use "Depends()" since it works with Pydantics Base Model
