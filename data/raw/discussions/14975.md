### Description

Since FastAPI 0.129.1 (PR #14953), UploadFile fields generate contentMediaType: "application/octet-stream" instead of format: "binary" in the OpenAPI schema. Swagger UI 5.x (bundled with FastAPI via CDN @5) does not render a file picker for contentMediaType — it shows a text input instead.

### Expected behavior

Swagger UI should show a file picker widget.

### Root cause

- FastAPI 0.129.1+ generates: {"type": "string", "contentMediaType": "application/octet-stream"}
- FastAPI 0.128.x generated: {"type": "string", "format": "binary"}
- Swagger UI 5.x only renders file pickers for format: "binary" (see https://github.com/swagger-api/swagger-ui/issues/9278)

### Workaround

Post-process the OpenAPI schema in custom_openapi():

```python
def _fix_file_upload_schemas(schema: dict) -> None:
    for component in schema.get("components", {}).get("schemas", {}).values():
        for prop in component.get("properties", {}).values():
            if prop.get("contentMediaType") == "application/octet-stream":
                del prop["contentMediaType"]
                prop["format"] = "binary"
            items = prop.get("items", {})
            if items.get("contentMediaType") == "application/octet-stream":
                del items["contentMediaType"]
                items["format"] = "binary"
```

## Accepted answer by JavierSanchezCastro (CONTRIBUTOR)

Hello!

You can try this workaround until this is fixed:

```python3
from fastapi import FastAPI, UploadFile as UF, File
from typing import Annotated
from pydantic import WithJsonSchema

app = FastAPI()

UploadFile = Annotated[UF, WithJsonSchema({"type": "string", "format": "binary"})]

@app.post("/upload")
async def upload(files: list[UploadFile] = File(...)):
    return {"count": len(files)}
```
