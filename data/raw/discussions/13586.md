### Example Code

```python
import typing
import fastapi

app = fastapi.FastAPI(root_path="/service", debug=True)

@app.get("/test")
def test(
	field: typing.Annotated[
		list[str] | None,
		fastapi.Query(pattern="[_a-zA-Z][_a-zA-Z0-9]*")
	]
):
	return {}
```

## Accepted answer by YuriiMotov (MEMBER)

You can use this approach:

```
import typing
import fastapi
import pydantic

app = fastapi.FastAPI(root_path="/service", debug=True)


MyType: typing.TypeAlias = typing.Annotated[
    str,
    pydantic.Field(pattern="[_a-zA-Z][_a-zA-Z0-9]*"),
]

@app.get("/test")
def test(
    field: typing.Annotated[list[MyType] | None, fastapi.Query()]
):
    return {}
```
