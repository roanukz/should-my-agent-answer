## Accepted answer by YuriiMotov (MEMBER)

`fastapi dev` command runs server on `127.0.0.1:8000` (instead of `0.0.0.0:8000` as if you use `fastapi run`), so you can only access server locally.

To make it accessible by network, try running it with `fastapi dev --host 0.0.0.0` command

Related part of docs: https://fastapi.tiangolo.com/fastapi-cli/#fastapi-dev
