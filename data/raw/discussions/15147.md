### Description

I would like to allow to set `data.superuser` to False only if there is at least one more superuser in db.
I would like to return a standard ValidationError response for `data.superuser` field like:

```
{
    "detail": [
        {
            "loc": [
                "body",
                "superuser"
            ],
            "msg": "Cannot demote the last superuser",
            "input": false
        }
    ]
}
```

I am aware that I could add a pydantic model validator to `UserUpdate` class that will query the database, but I do not like to move this validation logic outside route function.

Is there a way to mark superuser field as invalid in route function and throw ValidationError from there?

Or there is a better recommended way to do such type of validation?

## Accepted answer by BlackZork (NONE)

Finally I came with this solution:

```python
    if not other_superusers:
        raise DataConflictException(fields(UserUpdate).superuser, "Cannot demote the last superuser")
```

where exception is just derived from HTTPException:

```python
class DataConflictException(HTTPException):
    def __init__(self, field: str, msg: str, error_type: str = "data conflict"):
        self.detail = [{
            "loc": [
                "body",
                field
            ],
            "msg": msg,
            "type": error_type
        }]
        self.status_code = status.HTTP_409_CONFLICT
```

And field name helper is taken from [this discussion](https://github.com/pydantic/pydantic/discussions/8600):

```python
@dataclass(frozen=True)
class _GetFields:
    _model: type[BaseModel]

    def __getattr__(self, item: str) -> Any:
        if item in self._model.model_fields:
            return item

        return getattr(self._model, item)


TModel = TypeVar("TModel", bound=type[BaseModel])


def fields(model: TModel, /) -> TModel:
    return cast(TModel, _GetFields(model))


if not TYPE_CHECKING:
    fields = lru_cache(maxsize=256)(fields)
```
