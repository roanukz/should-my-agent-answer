## Accepted answer by sector119 (NONE)

```
@asynccontextmanager
async def lifespan(app: FastAPI):
    for route in app.routes:
        if isinstance(route, APIRoute):
            sig = signature(route.endpoint)
            route.openapi_extra = {...}
    yield


app = FastAPI(lifespan=lifespan)
```
