## Accepted answer by YuriiMotov (MEMBER)

It fails to verify audience.
I think you need to either specify audience
```
    payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM], audience="foo")  # Update with correct value

```

or disable audience verification:
```
    payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM], options={"verify_aud": False})

```
