## Accepted answer by YuriiMotov (MEMBER)

Thanks for reporting this.

These `.agents/skills/...` files are included intentionally. They are part of the [Library Skills](https://library-skills.io/) convention, where a library ships versioned agent skills inside the package so external tools can discover and install them.

The goal is for the skills to stay aligned with the installed FastAPI version, so shipping them with the published package is the point.
