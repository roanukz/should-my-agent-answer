### Description

# FastAPI BeforeValidator issue

We use Annotated + BeforeValidator to automatically convert query parameters like "items=a,b,c" into lists.

Starting in v0.118.2, the annotation doesn't work as expected anymore.

## Description

When using Annotated[..., BeforeValidator(function)] as a custom type conversion in query parameters, the function is not called.


## Versions

- 0.118.1 works ok
- 0.118.2 has the issue.

Probably introduced in https://github.com/fastapi/fastapi/pull/12942

## Accepted answer by YuriiMotov (MEMBER)

Before 0.118.2 there was a bug and FastAPI failed to correctly recognize the list type if it was specified using `Annotated` inside the `Union` (like `Annotated[list[str], Query()] | None`).

In 0.118.2 that bug was fixed and FastAPI now parses this parameter as list and passes list with one element to validator. You can see this in printed log: `BeforeValidator called with: ['a,b,c']`.

So, to fix your code example you need to modify `parse_comma_separated` to handle `value` parameter passes as list:

```
def parse_comma_separated(value: str | list | None) -> list[str] | None:
    """Convert comma-separated string to list."""
    print(f"BeforeValidator called with: {value!r}")  # Debug: see if this gets called
    if isinstance(value, list) and len(value) == 1:
        value = value[0]
    if isinstance(value, str):
        return [item.strip() for item in value.split(",") if item.strip()]
    return value
```

And, you don't need to use union in `items: CommaSeparatedList | None = None` - just `items: CommaSeparatedList = None` is correct since `CommaSeparatedList` is already `list[str] | None`
