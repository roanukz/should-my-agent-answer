## Accepted answer by DoctorJohn (MEMBER)

Hi, since you're using an UploadFile, FastAPI/Starlette will interpret and store your post data as a multipart form. This is done internally via `await request.form()` as soon as the request is received. After that, the raw request data is no longer available and therefore can not be accessed via `await request.body()`.

Ironically, if the post data is first accessed via `await request.body()` it is possible to access it again via `await request.form()`, because the raw request data can be reinterpreted as multipart form data.

This leaves us with three options:

1. Option: work with form data in your `credential` dependency
    
    ```python
    async def credential(request: Request):
        form = await request.form()
    ```

2. Option: interpret the post data yourself

    ```python
    async def credential(request: Request):
        body = await request.body()  # No longer raises a runtime error
    
    
    @app.post("/api")
    async def read_root(
        request: Request,
        credential: Any = Depends(credential),
    ):
        form = await request.form()
        file = form.get("file")
        return {"Hello": file.filename if isinstance(file, UploadFile) else "no file"}
    ```

3. Option: start a discussion in the Starlette repo
    I'm pretty sure it's a performance optimization that the raw post data is no longer available if it has been accessed via `await request.form()` first. However, technically, it would be possible to preserve the raw post data in that case.
