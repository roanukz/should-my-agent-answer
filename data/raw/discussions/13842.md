## Accepted answer by luzzodev (CONTRIBUTOR)

Hello @dasunprem, i don't know if you just missed it in the example, but you should define app.get as a decorator.

``` python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
# from rethinkdb import r

app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

@app.get("/")
async def root():
    return {"message": "Hello World"}
```
