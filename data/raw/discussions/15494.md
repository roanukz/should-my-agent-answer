### Example Code

```python
from collections.abc import Generator
from typing import Annotated, Any

from fastapi import Depends, FastAPI
from fastapi.responses import EventSourceResponse
from pydantic import BaseModel


class Item(BaseModel):
    name: str


def dep_session() -> Any:
    # yield dependency - cleanup should run after stream ends
    yield [Item(name="foo"), Item(name="bar")]


app = FastAPI()


@app.get("/sse", response_class=EventSourceResponse)
def sse_items(items: Annotated[list, Depends(dep_session)]) -> Any:
    def gen() -> Generator[Item, None, None]:
        yield from items

    return gen()
```


### Description

`test_dependency_after_yield_streaming.py` verifies that yield dependency cleanup runs correctly with `StreamingResponse`. There is no equivalent test for `EventSourceResponse` (SSE), which uses a different internal code path (`_sse_producer_cm` task group in `routing.py`).

I have written `tests/test_dependency_after_yield_sse.py` locally - 8 tests covering sync/async yield deps with SSE, cleanup verification, and broken dependency behaviour. All pass.

Would a PR adding this test file be welcome?

## Accepted answer by golikovichev (NONE)

Glad the suggestions landed. Your call to skip the client-disconnect test is reasonable for the sync TestClient path, the race window really is too tight to assert anything meaningful. If you ever want to cover it later, the async route works: `httpx.AsyncClient` plus an explicit `aclose()` call mid-stream, then assert the cleanup sentinel ran exactly once. Lower priority though, the four tests you added cover the load-bearing cases.

Good luck with the PR. Happy to look at the diff if you open one.
