### Description

This is distinct from these prior issues -
- https://github.com/fastapi/fastapi/discussions/11852
- https://github.com/fastapi/fastapi/discussions/9409
- https://stackoverflow.com/questions/73078330/fastapi-request-body-returns-null-from-checkbox-html-tag

HTML forms submit no value when a checkbox is unchecked, and submit a string (default `"on"` when checked). By the time the value is received by the pydantic model, either through a field or a model validator, it either is a) the explicitly provided string value, or b) the default value. 

If the default value is `True`, it is impossible to differentiate an explicit `True` from a default `True` in the model itself, so one can't write a model validator that can be used both with the form input case and programmatic usage. 

Since the problem is a matter of the HTML standards not providing a bool, checkboxes are unambiguously booleans, the boolean status is invisible at the point of model instantiation but NOT at the point that FastAPI parses the form data (not present is `False` and a string is `True`), it should be the FastAPI form handling logic that casts it to a bool prior to reaching the model. This would resolve the above issues as well without needing to resort to awkward workarounds. 

The prior workarounds do not apply to this case, since there either were no defaults or the defaults were `False` - the problem in this case is specifically that a default of `True` is not possible with form inputs.

I am more than happy to write a PR for this if maintainers agree :)

This is the only way i have found to make it work, but it is very not DRY to have to do this for every checkbox in a way that is not bundled with the model.

```python
@app.post("/form")
async def endpoint(
    request: Request,
    model: Annotated[MyModel, Form()],
):
    form = await request.form()
    model.checkbox = "checkbox" in form
```

## Accepted answer by sneakers-the-rat (NONE)

If https://github.com/fastapi/fastapi/pull/13464 is merged, then the workaround for this would be

```python
from pydantic import BaseModel, Field, model_validator

class MyModel(BaseModel):
    checkbox: bool = True

    @model_validator(mode="before")
    @classmethod
    def unset_bools_are_false(cls, value: dict) -> dict:
        """
        unchecked checkboxes in HTML forms are encoded as the field key being absent,
        rather than indicating an explicit `False`
        """
        if "checkbox" not in value:
            value["checkbox"] = False

```

so this should pass

```python
import pytest
from typing import Annotated
from fastapi import FastAPI, Form

app = FastAPI()

@app.post("/")
def form_endpoint(model: Annotated[MyModel, Form()]):
    return model

@pytest.fixture(scope="module")
def client() -> TestClient:
    with TestClient(app) as test_client:
        yield test_client

def test_unchecked_box_is_false(client):
    res = client.post("/", data={})
    assert not MyModel(**res.json()).checkbox

def test_checked_box_is_true(client):
    res = client.post("/", data={"checkbox": "on"})
    assert MyModel(**res.json()).checkbox

```
