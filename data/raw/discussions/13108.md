## Accepted answer by YuriiMotov (MEMBER)

You can [mount](https://fastapi.tiangolo.com/advanced/sub-applications/) frontend as a sub-app. This way docs will be separated and you will be able to access frontend docs via '/front/docs':
```
from fastapi import FastAPI

app = FastAPI(title="Back-end app")

front_app = FastAPI(title="Front-end app")
app.mount("/front", front_app)

```
