### Description

From the official documentation we know that we can use Pydantic models to declare form fields in FastAPI (https://fastapi.tiangolo.com/tutorial/request-form-models/). 

We also know from the offical documentation that we can define files and form fields at the same time using File and Form (https://fastapi.tiangolo.com/tutorial/request-forms-and-files/).

Now, Is it possible to combine the both above, namely, define File and Form fields where the Form fields are defined using a pydantic model? For example:

```python
from fastapi import FastAPI, Form, UploadFile, File
from pydantic import BaseModel, Field
from typing_extensions import Annotated

app = FastAPI()

class FormData(BaseModel):
    username: str = Field(
        ..., description="The username of the user", min_length=3
    )
    password: str = Field(
        ..., description="The password of the user", min_length=6
    )


@app.post("/login/")
async def login(
    data: Annotated[FormData, Form()],
    file: Annotated[UploadFile, File()],
):
    """
    dummy endpoint
    """
```

## Accepted answer by YuriiMotov (MEMBER)

There is a limitation (bug?) in current version that you can't combine Form parameters defined with Pydantic model with other Form\File parameters.

You can include `file` parameter into `FormData` model:
```python
from fastapi import FastAPI, Form, UploadFile, File
from pydantic import BaseModel, Field
from typing_extensions import Annotated

app = FastAPI()

class FormData(BaseModel):
    username: str = Field(
        ..., description="The username of the user", min_length=3
    )
    password: str = Field(
        ..., description="The password of the user", min_length=6
    )
    file: Annotated[UploadFile, File()]


@app.post("/login/")
async def login(
    data: Annotated[FormData, Form(media_type="multipart/form-data")],
):
    """
    dummy endpoint
    """
    pass
```

If that `FormData` model comes from another module and you can't modify it, you can inherit from it and add the `file` field:

```python
class FormFileData(FormData):
    file: Annotated[UploadFile, File()]
```


**UPD:** Note, that you need to use `Form(media_type="multipart/form-data")` to make it working
