### Example Code

```python
from fastapi import FastAPI, UploadFile, File, Form, APIRouter

router = APIRouter()

@router.post("/upload")
async def test(
    myfile: UploadFile = File(..., description="File to upload"),
    user_id: int = Form(..., description="User ID", alias="userId"),
):
    return {"user_id": user_id}
```


### Description

I’ve noticed that when using `Form` parameters with an `alias`, the alias is not displayed in Swagger UI. Instead, the original Python name is shown.  

**Expected behavior**
In the generated Swagger UI, the parameter should be displayed as userId (the alias).

**Actual behavior**
Swagger shows the parameter as user_id (the original field name).

## Accepted answer by YuriiMotov (MEMBER)

It's known issue: https://github.com/fastapi/fastapi/issues/10286

The workaround is to specify `validation_alias` in addition to `alias`:
```py
from fastapi import FastAPI, UploadFile, File, Form, APIRouter

app = FastAPI()

@app.post("/upload")
async def test(
    myfile: UploadFile = File(..., description="File to upload"),
    user_id: int = Form(..., description="User ID", alias="userId", validation_alias="userId"),
):
    return {"user_id": user_id}
```
