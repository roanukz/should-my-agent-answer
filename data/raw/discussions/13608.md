### Description

Description: I am using FastAPI with routers and access tokens to fetch user data. When I send a request using Postman, the request is successful, and the expected response is returned. However, when I try the same request using Swagger (FastAPI's auto-generated docs), I receive a "Not Found" error.

Steps to Reproduce:

Define a route that requires an access token, as shown in the provided code snippet.
Send a request to the route using Postman with the correct access token.
Observe that the request is successful.

## Accepted answer by luzzodev (CONTRIBUTOR)

Hello @m8811163008,

swagger is expecting to received this response format from `login_for_access_token`
```
{"access_token": "<scecret-access-token>", "token_type": "bearer"}
```
I'm quite sure you are not returning that format and swagger will read 'access_token' as undefined.
