### Example Code

```python
from typing import Annotated

from fastapi import Body, FastAPI
from pydantic.json_schema import SkipJsonSchema

app = FastAPI()


@app.post("")
def a(
    b: Annotated[
        dict[int, int] | SkipJsonSchema[None],
        Body(json_schema_extra={"default": {1: 1}})
    ] = None
):
    if b is None:
        b = {1: 1}


import json
print(json.dumps(app.openapi(), indent=4))
```


### Description

I want to set a default value in the JSON schema using the json_schema_extra parameter of Body(). For classical Pythonic reasons, I don’t want to use a dictionary as the default value in the function. Instead, I set the default to None and want the schema to show {"default": {1: 1}}. But it doesn’t appear in the schema.
Important part of JSON schema:
```
                "requestBody": {
                    "content": {
                        "application/json": {
                            "schema": {
                                "additionalProperties": {
                                    "type": "integer"
                                },
                                "type": "object",
                                "title": "B"
                            }
                        }
                    }
                },
```

## Accepted answer by YuriiMotov (MEMBER)

You are right. Sorry for wrong answer 🙏.

Seems that for now the only way is to specify it in `openapi_extra` of path decorator:

```python
@app.post(
    "/a",
    openapi_extra={
        "requestBody": {"content": {"application/json": {"schema": {"default": {12: 34}}}}}
    },
)
def a(
    b: Annotated[dict[int, int] | SkipJsonSchema[None], Body()] = None,
):
    if b is None:
        b = {1: 1}
```

```json
                "requestBody": {
                    "content": {
                        "application/json": {
                            "schema": {
                                "additionalProperties": {
                                    "type": "integer"
                                },
                                "type": "object",
                                "title": "B",
                                "default": {
                                    "12": 34
                                }
                            }
                        }
                    }
                },
```

FastAPI creates `requestBody` combining together all `Body` parameters. And it misses their default values (as well as examples). I think that might be improved. At least in case there is only one `Body` parameter.
