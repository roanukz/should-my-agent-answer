## Accepted answer by YuriiMotov (MEMBER)

I got it!

When the unhandled exception happens in your endpoint, it goes through the whole middleware stack and finally gets to `ServerErrorMiddleware`. Then `ServerErrorMiddleware` sends the response. At this moment we are already outside of `CORSRiddleware`, so, it can't modify the response.

The only way I can see here is to handle exception in the endpoint function, raise custom exception and handle it with exception handlers:

```python
from fastapi import FastAPI, HTTPException, Request
from fastapi.responses import JSONResponse
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel

class EdgResponse(BaseModel):
    error_code: int
    error_message: str


class FatalError(HTTPException):
    pass


app = FastAPI()

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/")
async def index():
    try:
        # do something
        raise Exception("12345")
    except Exception as e:
        raise FatalError(status_code=500, detail=str(e))


def set_exception_handler(app: FastAPI):

    @app.exception_handler(FatalError)
    async def edg_exception_handler(_: Request, exc: FatalError):
        content = EdgResponse(error_code=exc.status_code, error_message=exc.detail)
        return JSONResponse(
            status_code=exc.status_code,
            content=content.model_dump()
        )


set_exception_handler(app)

```
