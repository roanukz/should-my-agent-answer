## Accepted answer by jgould22 (NONE)

All the tests pass for me on python3.12 but in a container with 3.13 I do also get that error. 

My guess is something in anyio[trio]==3.7.0 doesnt like python 3.13.

In 4.5 they mention 
> Added support for the from_uri(), full_match(), parser methods/properties in anyio.Path, newly added in Python 3.13 

So likely because you have 3.13 you getting caught by one of these guys 

https://github.com/agronholm/anyio/pull/740/files#diff-9b0ada949bf00d8698315dbb297a59d14aa291fe7b2405a7bd335d0a7e66d356R361

Looks like if you bump anyio to `4.5` four of the tests fail so the answer is probably for those tests to be debugged and then for anyio to be bumped

The shortest term fix is of course to use 3.12 if that is possible.
