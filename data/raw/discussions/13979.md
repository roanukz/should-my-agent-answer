## Problem Description

When uploading Excel files (.xlsx) through FastAPI's `UploadFile`, the files become corrupted during the upload processing phase, before any user application code handles them. The same endpoint works perfectly with CSV files, suggesting the issue is specific to binary file handling.

### Error Message
```
openpyxl.utils.exceptions.InvalidFileException: openpyxl does not support the old .xls file format, use xlrd to read this file, or convert it to the newer .xlsx format. Bad magic number for central directory
```

Note: The error mentions .xls but the uploaded file is .xlsx. The "Bad magic number" indicates ZIP archive corruption (XLSX files are ZIP-based).

Second, could you create a code example without external dependencies?

The following code example receives file, saves it to tmp file and asserts that first bytes remain unchanged:

```py
from fastapi import FastAPI, File, UploadFile

app = FastAPI()


@app.post("/upload")
async def upload_file(file: UploadFile = File(...)):
    # Reset file pointer
    await file.seek(0)

    # Read file content
    content = await file.read()

    assert content.startswith(b"PK\x03\x04")

    # Save to temporary file
    temp_path = f"/tmp/{file.filename}"
    with open(temp_path, "wb") as f:
        f.write(content)

    with open(temp_path, "rb") as f:
        content_read = f.read()

    assert content_read.startswith(b"PK\x03\x04")

    return "ok"
```

This code works well on my machine. I see you are using Windows. Does it work on your machine?
