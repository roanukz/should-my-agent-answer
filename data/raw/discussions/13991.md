### Example Code

```python
from fastapi import FastAPI, Query
from pydantic import BaseModel


class C(BaseModel):
    cname: str

class B(BaseModel):
    bname: str
    child: C

class A(BaseModel):
    aname: str
    child: B

app = FastAPI()

@app.get("/")
def route(a: A = Query()):
    return a

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="localhost", port=7777)
```


### Description

* Open browser
* Call `/` endpoint and fill out `aname` with something random
* It makes the following request `http://localhost:7777/?aname=asdf&bname=string&child=%7B%22cname%22%3A%22string%22%7D`
* You receive the following error

```json
{
  "detail": [
    {
      "type": "model_attributes_type",
      "loc": [
        "query",
        "child"
      ],
      "msg": "Input should be a valid dictionary or object to extract fields from",
      "input": "{\"cname\":\"string\"}"
    }
  ]
}
```

* It's unclear how to use nested models in query parameter or if they're supported in fastapi.

## Accepted answer by YuriiMotov (MEMBER)

FastAPI doesn't support nested models for query parameters.
Supporting [DeepObject serialization](https://github.com/fastapi/fastapi/issues/3163) would be helpful here.

For now, use `Body` parameters (as @valentinDruzhinin suggested) or consider using the following idea:

Change type of `A.child` to `Json[B]` and override its schema using `WithJsonSchema`
```py
class A(BaseModel):
    aname: str
    child: Annotated[Json[B], WithJsonSchema({"type": "string"})]
```

Runnable code example:

```py
from typing import Annotated

from fastapi import FastAPI, Query
from pydantic import BaseModel, Json, TypeAdapter, WithJsonSchema

class C(BaseModel):
    cname: str

class B(BaseModel):
    bname: str
    child: C

class A(BaseModel):
    aname: str
    child: Annotated[Json[B], WithJsonSchema({"type": "string"})]

app = FastAPI()
AAdapter = TypeAdapter(A)

@app.get("/")
def route(a: A = Query()):
    return a
```
Send request as `http://localhost:8000/?aname=a&child=%7B%22bname%22%3A%20%22b%22%2C%20%22child%22%3A%20%7B%22cname%22%3A%20%22c%22%7D%7D`.
Here the part after `child=` is url-encoded value of `{"bname": "b", "child": {"cname": "c"}}`.
This way you will have request validation working for nested models
