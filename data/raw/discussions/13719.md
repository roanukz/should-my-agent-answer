## Accepted answer by YuriiMotov (MEMBER)

This comes from `TestClient` (actually, from `httpx` which is used internally in `TestClient`).

Run the following code:

```
import httpx

res = httpx.post(
    "http://localhost:8000/uploadfile/",
    files={"test_file": b"123456"},
)

print(res.request.read())
```

And you will see the request that `httpx` sends:

```
b'--81555b625e6be0c1753b0a563f634b9c\r\nContent-Disposition: form-data; name="test_file"; filename="upload"\r\nContent-Type: application/octet-stream\r\n\r\n123456\r\n--81555b625e6be0c1753b0a563f634b9c--\r\n'
```

Notice that `filename="upload"` is sent in request.

So, this is not a FastAPI issue
