### Example Code

```python
from fastapi import FastAPI, BackgroundTasks
import asyncio
import datetime
app = FastAPI()

async def test_task():
    await asyncio.sleep(2)
    print(datetime.datetime.now(), "hello")
@app.get("/")
async def root(bg_task: BackgroundTasks):
    for _ in range(4):
        bg_task.add_task(test_task)
    return {"message": "Hello World"}
```


### Description

the 4 test_task added here will run sequentially. is there a way to make them run concurrently? so they all end in about 2 seconds.

## Accepted answer by YuriiMotov (MEMBER)

There is no way to configure FastAPI to run background tasks concurrently, but you can use the following approach:

```python
import asyncio
from fastapi import BackgroundTasks, FastAPI

async def concurrent_tasks(tasks: list[asyncio.Task]) -> None:
    await asyncio.gather(*tasks)

app = FastAPI()

async def test_task():
    await asyncio.sleep(2)
    print(datetime.datetime.now(), "hello")

@app.post("/foo")
def foo(background_tasks: BackgroundTasks):
    tasks = [test_task() for n in range(1, 4)]
    background_tasks.add_task(concurrent_tasks, tasks)    
    return {"message": "Hello World"}
```

It will add one background task, that runs all your `async` tasks concurrently inside
