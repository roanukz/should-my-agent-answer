## Accepted answer by sachinh35 (NONE)

Hi Hussain, welcome to Fast API! The documentation is the best place to get started with FastAPI. I'm by no means an expert on FastAPI but I think the more you work on it the more you'll learn about it. So I would recommend to also implement things along the side on your own as you're reading documentation. 

It's hard to specifically recommend how to use Fast API for building LLM apps as it'll depend on a lot of things and there's no one-size-fits-all solution. But here are a couple of articles that can be helpful in terms of using Fast API:
1. https://medium.com/@igorbenav/creating-llm-powered-apis-with-fastapi-in-2024-aecb02e40b8f
2. https://medium.com/@ramanbazhanau/preparing-fastapi-for-production-a-comprehensive-guide-d167e693aa2b

The articles might not be exactly relevant to your use case but they seem like a good place to start. Besides the articles, check out these external links on Fast API's documentation which point to a lot of resources related to Fast API: https://fastapi.tiangolo.com/az/external-links/ 

I hope this helps and happy coding!
