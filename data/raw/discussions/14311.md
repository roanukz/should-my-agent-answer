## Accepted answer by YuriiMotov (MEMBER)

Yes, using dataclasses this way (with `Query`) is not documented and not supported.
Either use Pydantic model with `Query` as [described here](https://fastapi.tiangolo.com/tutorial/query-param-models/), or use dataclass with `Depends` as [described here](https://fastapi.tiangolo.com/tutorial/dependencies/classes-as-dependencies/).

I don't think we need to update docs - they are clear about the Query parameter models working with Pydantic models:

> If you have a group of **query parameters** that are related, you can create a **Pydantic model** to declare them

Source: https://fastapi.tiangolo.com/tutorial/query-param-models/
