### Example Code

```python
from contextlib import asynccontextmanager
from typing import Annotated

from fastapi import Depends, FastAPI

app = FastAPI()


@asynccontextmanager
async def get_hi():
    try:
        print('try')
        yield 'hi'
    finally:
        print("finally")


@app.get('/')
async def say_hi(hi: Annotated[str, Depends(get_hi)]):
    print(hi)
    # <contextlib._AsyncGeneratorContextManager object at 0x7911adb11550>
```

## Accepted answer by YuriiMotov (MEMBER)

Could you explain the purpose of using context manager in your use case? I mean, why do you need to decorate `get_hi` with `@asynccontextmanager`?

You can fix your code by just removing `@asynccontextmanager` decorator. FastAPI will recognize the generator and create the context manager out of it.

Regarding #11143: as I see it, that issue is not about passing context managers to `Depends`, but about using context managers inside dependencies with `yield` (the behavior of such dependencies was changed in v0.106.0).
