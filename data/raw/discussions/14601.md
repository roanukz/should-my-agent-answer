### Example Code

```python
from typing import Annotated, Literal

from fastapi import FastAPI, Query, Depends
from pydantic import BaseModel

app = FastAPI()

class ItemParams(BaseModel):
    item_id: int | None = None
  
    @field_validator("item_id", mode="before")
    @classmethod
    def return_none_if_undefined(cls, v: str):
        if v in ["undefined", "null", ""]:
            return None

        return v

@app.get("/items")
async def get_items(
    ItemParams: Depends()
```

### Description

As the title says, `@field_validator("item_id", mode="before")` doesn’t seem to work for FastAPI query parameters. I spent hours debugging and thought it was a Pydantic bug at first, but the same validator works perfectly when used in the request body.

You can reproduce the issue by copy-pasting the code above—it returns a 422 error.

## Accepted answer by YuriiMotov (MEMBER)

Using Pydantic model to declare Query parameter this way (with `Depends()`) was never officially supported by FastAPI.

The correct way to declare Query parameters with Pydantic models is described in https://fastapi.tiangolo.com/tutorial/query-param-models/

```py
from typing import Annotated

from fastapi import FastAPI, Query
from fastapi.testclient import TestClient
from pydantic import BaseModel, field_validator

app = FastAPI()


class ItemParams(BaseModel):
    item_id: int | None = None

    @field_validator("item_id", mode="before")
    @classmethod
    def return_none_if_undefined(cls, v: str):
        if v in ["undefined", "null", ""]:
            print("Converting to None")
            return None

        return v


@app.get("/items")
async def get_items(q: Annotated[ItemParams, Query()]) -> None:
    pass


client = TestClient(app)


def test_pass_empty_str():
    response = client.get("/items?item_id=")
    assert response.status_code == 200


def test_pass_undefined_str():
    response = client.get("/items?item_id=undefined")
    assert response.status_code == 200

```

Also, FastAPI treats empty string passed as Query parameter as not passing the parameter. So, default value is used and will be passed to validator
