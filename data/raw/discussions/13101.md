### Description

## Accepted answer by YuriiMotov (MEMBER)

The way you are running blocking code inside an async function is wrong.
`list(executor.map(...))` will block async loop until all sync functions have been finished execution. So, your server will not be able to process other requests during this time.

To fix this, run sync code using this approach:
```
@app.get("/all_answers")
async def all_answers():
    loop = asyncio.get_running_loop()
    with ThreadPoolExecutor(max_workers=50) as executor:
        tasks = [
            loop.run_in_executor(executor, prepare_question_data, question_id)
            for question_id in question_ids
        ]
        results = await asyncio.gather(*tasks)
    return results
```

To futher optimize this code, create single `ThreadPoolExecutor` instance on you application run (in lifespan) and use it instead of creating new pool every time
