## Question

Hello everyone,

I’m looking for a robust and stable admin panel solution for FastAPI, similar to Django Admin for Django. Ideally, it should be well-maintained, production-ready, and capable of handling complex applications.

## Accepted answer by sinisaos (NONE)

@apiguy123 You have several options based on the ORM you are using. If you use SqlAlchemy, SQLModel, Tortoise ORM, etc. you can try 
[Fastadmin](https://github.com/vsdudakov/fastadmin), [Starlette-admin](https://github.com/jowilf/starlette-admin) or [SQLAdmin](https://github.com/aminalaee/sqladmin). If you are using Piccolo ORM you can try [Piccolo Admin](https://github.com/piccolo-orm/piccolo_admin). Hope that helps.
