### Description

I want the functionality, that if someone sends a request to an LLM, and then they reload the page during the response, the information will still be sent. Currently how I aim to do that is by detecting a client disconnect through Request.is_disconnected(), and then putting the chunks in a queue in the state attribute of FastAPI, and then streaming from the queue with a second request that is given the same request id. But from my testing, and from what these two links talk about: #7572 and this [blog](https://fastapiexpert.com/blog/2024/06/06/understanding-client-disconnection-in-fastapi/), it seems like a StreamingResponse will automatically detect for a client disconnect and raise a asyncio.CancelledError exception. Is there any way to stop this from occurring, either through how the StreamingResponse is called or otherwise?

## Accepted answer by YuriiMotov (MEMBER)

> StreamingResponse will automatically detect for a client disconnect and raise a asyncio.CancelledError exception. Is there any way to stop this from occurring

No, there is no such option.

I think the only way to achieve what you want is to run `async` task (using `asyncio.create_task`) that will generate data and save it somewhere. And, the generator function of `StreamingResponse` should take that saved data and return it.
Then, if client send request with the same id, you can take that saved data and return it instead of generating it again.


```python
import asyncio
import dataclasses
from fastapi import FastAPI
from fastapi.responses import StreamingResponse


@dataclasses.dataclass
class GeneratedData:
    last_sent: int = -1
    finished: bool = False
    chunks: list[bytes] = dataclasses.field(default_factory=list)


data_storage: dict[str, GeneratedData] = {}


async def data_generator(generated_data: GeneratedData):
    for i in range(5):
        await asyncio.sleep(1)
        print("Generating data chunk", i)
        generated_data.chunks.append(f"Chunk {i}".encode())
    generated_data.finished = True


async def send_data_generator(generated_data: GeneratedData):
    i = generated_data.last_sent + 1
    while (i < len(generated_data.chunks)) or (not generated_data.finished):
        if i < len(generated_data.chunks):
            print("Send data chunk", i)
            yield generated_data.chunks[i]
            generated_data.last_sent = i
            i += 1
        else:
            await asyncio.sleep(0.1)


app = FastAPI()


@app.get("/", response_class=StreamingResponse)
async def end_pint(
    req_id: str,
):
    if req_id not in data_storage:
        data_storage[req_id] = GeneratedData()
        asyncio.create_task(data_generator(data_storage[req_id]))

    return StreamingResponse(send_data_generator(generated_data=data_storage[req_id]))

```
