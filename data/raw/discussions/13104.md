## Accepted answer by sehraramiz (NONE)

i tried this code you provided and its working, i don't get any errors and also got the request object in the dependency call.
i think what you provided as sample code is not coordinated with your provided error message. please test this fixed single file code and let us know the result. maybe you are missing some additional code from your main project.

```python

  from typing import Optional, List
  from starlette.requests import Request
  from fastapi import Header, Depends
  from fastapi import FastAPI
  from pydantic import BaseModel
  from fastapi import APIRouter


  app = FastAPI()


  class AuthenticationChecker:
      def __init__(self, required_role: Optional[str] = None):
          self.required_role = required_role

      async def __call__(
          self, request: Request, x_access_token: str = Header(None)
      ) -> bool:
          print(request)


  router = APIRouter()


  class ConfigRequest(BaseModel):
      project: str
      config_type: str
      config_data: List[str]


  @router.post("/set_config")
  async def set_config(config_request: ConfigRequest):
      pass


  admin_auth = AuthenticationChecker(required_role="Admin")

  app.include_router(
      router,
      prefix="/mgmt",
      tags=["management"],
      dependencies=[Depends(admin_auth)],
  )

```
