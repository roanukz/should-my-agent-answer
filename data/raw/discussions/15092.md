### Description

In [JSON Performance](https://fastapi.tiangolo.com/advanced/custom-response/#json-responses) docs there is an example with the return type annotation that provides the best serialization performance. 

Does this work in case where we specify the return model through the decorator response_model param and use Any for the return type annotation as in the example above?

## Accepted answer by YuriiMotov (MEMBER)

Yes!

Two conditions should be met:
* Specify `response_model` (by specifying return type annotation or by setting `response_model`)
* don't specify `response_class` and `default_response_class`
