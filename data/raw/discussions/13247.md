### Description

Hello,

When authenticating with entraID i do get both the **token** and the **refresh token** set in the browser cookies but i would like to know how to obtain the refresh token on the backend as well.

The `HTTPAuthorizationCredentials` object does not have a key for that and i am wondering if there is a better type/object to use for this scenario.

Thank you

## Accepted answer by YuriiMotov (MEMBER)

To get it on your backend your frontend should send it alongside `token`. Does it send it?

If yes, just add `Header` parameter:
```python
@app.get("/auth")
async def auth(
    creds: Annotated[HTTPAuthorizationCredentials | None, Depends(token_auth_scheme)],
    refresh_token: Annotated[str | None, Header()] = None,
) -> dict:

```
