### Example Code

```python
import uvicorn
from fastapi import FastAPI
from fastapi.responses import StreamingResponse

app = FastAPI()


async def fake_video_streamer():
    for i in range(10):
        yield b"some fake video bytes"


@app.get("/")
async def main():
    return StreamingResponse(fake_video_streamer())


if __name__ == "__main__":
    uvicorn.run(app, loop="asyncio")
    #uvicorn.run(app)  # crash! ERROR:    Exception in ASGI application
```


### Description

When using StreamingResponse in the following code, running the application with the default uvicorn.run(app) configuration causes the application to crash with an Exception in ASGI application error. However, explicitly setting loop="asyncio" resolves the issue.
