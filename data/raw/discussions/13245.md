### Example Code

```python
from fastapi import FastAPI, Depends

app = FastAPI()

async def async_dependency():
    print("Async Setup")
    yield "Async Resource"
    print("Async Cleanup")

def sync_dependency():
    print("Sync Setup")
    yield "Sync Resource"
    print("Sync Cleanup")

@app.get("/async")
async def read_async(resource=Depends(async_dependency)):
    return {"resource": resource}

@app.get("/sync")
def read_sync(resource=Depends(sync_dependency)):
    return {"resource": resource"}
```


### Description

We are using the Depends in the two endpoints. First one is using asynchronous dependency and second one is using synchronous dependency. How does the fast api Depends knows that the dependency should be using a AsyncContextManager or SyncContextManager? 

I think the fastapi uses internally this function call
```
inspect.iscoroutinefunction()
```

to know that the function is a sync or asynchronous.

## Accepted answer by luzzodev (CONTRIBUTOR)

Hello @syedvolkswagen,

fastapi while is solving dependencies will check what kind of dependency is trying to solve. If async it will be awaited, if sync will be wrapped in a thread and awaited.

Yes, it uses `inspect.iscoroutinefunction()` but checks few things more.
