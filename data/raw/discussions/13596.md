### Description

` val requestBody: RequestBody = RequestBody.create(contentType = "application/octet-stream".toMediaTypeOrNull(), content = dataByteArray)`
            
`Log.d("Main", "request body size: ${requestBody.contentLength()}")
`

## Accepted answer by alv2017 (CONTRIBUTOR)

@rabyunghwa,

Have a look at the souce code reference of the Request class: https://fastapi.tiangolo.com/reference/request/
Methods: `async def stream()`, `async def body()`
It seems that Starlette processes request data as a bytestring.
Probably this is the reason of those extra 33 bytes. :smiley:

You can double-check this hypothesis by writing a unit test !  

And it turns out that `sys.getsizeof()` is not showing what we normally expect it to:
https://nedbatchelder.com/blog/202002/sysgetsizeof_is_not_what_you_want.html

``` python

import os
import sys

data = [os.urandom(0), os.urandom(1), os.urandom(2)]

print([(item, sys.getsizeof(item)) for item in data])
```

All in all there is a room for investigation :smile:
