### Example Code

```python
from typing import Annotated

import uvicorn
from fastapi import FastAPI, Depends
from pydantic import BaseModel, field_validator

app = FastAPI()

class QueryArgs(BaseModel):
    x: str | None = None

    @field_validator("x")
    @classmethod
    def x_must_not_be_y(cls, v):
        if v != "y":
            raise ValueError("x must be 'y'")
        return v


@app.get("/")
async def get(qa: Annotated[QueryArgs, Depends()]) -> str:
    return f"OK: {qa.x}"
```

## Accepted answer by luzzodev (CONTRIBUTOR)

Hello @twalcari,

The supported and official way to define query params using a BaseModel is:

```python
async def get(qa: Annotated[QueryArgs, Query()]) -> str:
    return f"OK: {qa.x}"
```
Depends can be used in that way (unofficially) in some cases, but then you have the responsibility to properly handle and raise exceptions.

In the example you provided, there is no issue with using Query(). It’s likely that you are using more than one model as a query dependency (which is not supported), and that’s why the documentation shows the input in that way.
