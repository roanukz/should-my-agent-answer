### Description

I've added the following code to my app:

```
@app.get("/v0/my_obj/{objectid}")
def get_my_obj(
    session: SessionDep,
    objectid: int = fastapi.Path(..., example = 5)
) -> list[MY_OBJ]:
```

The app generates the following warning during startup:

DeprecationWarning: `example` has been deprecated, please use `examples` instead

The new examples config is useful when describing the full shape of an object. However, my API returns a list of objects, and there is no way to define default params on a list without using the fastapi.Path hint shown above.

## Accepted answer by YuriiMotov (MEMBER)

`example` property is deprecated by openapi specification. FastAPI just follows the specification.

See: https://spec.openapis.org/oas/v3.1.0#fixed-fields-19

<img width="808" height="224" alt="image" src="https://github.com/user-attachments/assets/eff15d1e-49b3-4265-b30f-a2338b339de3" />

---

Use `examples` and `openapi_examples`:

```py
from typing import Annotated

from fastapi import FastAPI, Path
from pydantic import BaseModel, Field


class MY_OBJ(BaseModel):
    id: Annotated[int, Field(examples=[5])]
    name: Annotated[int, Field(examples=["object name example"])]

app = FastAPI()

@app.get("/v0/my_obj/{objectid}")
def get_my_obj(
    objectid: int = Path(..., openapi_examples={"example1": {"value": 5}}),
) -> list[MY_OBJ]:
    pass

```
