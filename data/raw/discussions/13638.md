### Description

As per title, is there any way to execute some code _after_ a response has been sent, including in case of failure? I have some cleanup logic that should always run after a [StreamingResponse](https://fastapi.tiangolo.com/advanced/custom-response/#streamingresponse) has finished.

[Background Tasks](https://fastapi.tiangolo.com/tutorial/background-tasks/) are designed to "run after returning a response", but only if it's successful.

[Dependencies with yield](https://fastapi.tiangolo.com/tutorial/dependencies/dependencies-with-yield/) let you put some code in a `finally` block after `yield` which is "executed after creating the response but _before_ sending it", so before the StreamingResponse has finished.

I also tried writing a [custom APIRoute](https://github.com/fastapi/fastapi/discussions/8565#discussioncomment-5152849), but again the cleanup code seems to run _before_ the `StreamingResponse` completes.

## Accepted answer by YuriiMotov (MEMBER)

Just add this logic to the generator function of your streaming response:

```python
import asyncio

from fastapi import FastAPI
from fastapi.responses import StreamingResponse

app = FastAPI()


async def stream_test():
    try:
        for i in range(10):
            yield f"data: {i}\n"
            await asyncio.sleep(1)
        print("streaming completed")
    finally:
        print("clean up logic here")


@app.get("/")
async def stream():
    return StreamingResponse(stream_test(), media_type="text/event-stream")
```
