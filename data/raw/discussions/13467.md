## Accepted answer by luzzodev (CONTRIBUTOR)

Hello @kjathar123,

Your Pydantic model is expecting an application/json while UploadFile multipart/form-data.

Fastapi support multipart/form-data in the following way.

```python
@app.post("/")
async def example(
        file: Annotated[UploadFile, File()],
        name: Annotated[str, Form()],
        age: Annotated[int, Form()]

):
    return {"message": "Success", "filename": file.filename, "name": name, "age": age}
```
Ref to https://fastapi.tiangolo.com/tutorial/request-files/
