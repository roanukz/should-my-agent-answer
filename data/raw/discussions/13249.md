### Description

Trying to dynamically enable/disable the swagger docs causes unexpected behaviour which could cause serious security risks.
FastAPI by default has the docs enabled. If you try to disable them after instantiation, it will not work.
Confusing is that if you initally disable the docs, you can later enable them, but you cannot again disable them.
Disabling later seems to be somewhere messed up.

## Accepted answer by YuriiMotov (MEMBER)

Why don't you just use this approach?

```
ENABLE_DOCS = # Some logic here
DOCS_URL = "/docs" if ENABLE_DOCS else None
REDOC_URL = # ...
OPENAPI_URL = # ...

app = FastAPI(docs_url=DOCS_URL, redoc_url=REDOC_URL, openapi_url=OPENAPI_URL)
```

I think approach with enabling docs and then disabling them with `app.docs_url = None` is confusing by its own and you should avoid this
