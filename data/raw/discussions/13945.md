## Accepted answer by YuriiMotov (MEMBER)

For now FastAPI [doesn't support Deep object serialization](https://github.com/fastapi/fastapi/issues/3163).

You may consider using the following approach:
```py
from fastapi import FastAPI, Query
from pydantic import BaseModel, Json

app = FastAPI()

class Object(BaseModel):
  a: str
  b: str

@app.get("/")
def read_root(q: list[Json[Object]] = Query()):
    return {"query": q}
```

Pass parameters as URL-encoded JSON:
```
curl -X 'GET' \
  'http://localhost:8000/?q=%7B%22a%22%3A%22s1%22%2C%22b%22%3A%22s2%22%7D&q=%7B%22a%22%3A%22s3%22%2C%22b%22%3A%22s4%22%7D' \
  -H 'accept: application/json'
```
