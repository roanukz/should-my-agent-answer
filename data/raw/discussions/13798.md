### Example Code

```python
from fastapi import APIRouter
from pydantic import BaseModel


class ErrorSchema(BaseModel):
    error_type: str
    message: str
    detail: str | None = None


class APIErrorResponseSchema(BaseModel):
    error: ErrorSchema

    model_config = {
        "json_schema_extra": {
```

### Description

I'd like to thoroughly document all possible responses of my endpoints - including meaningful examples for additional responses defined on the router level.

With the code above, Swagger/Redoc correctly render the 500 Internal Server Error with the example specified in the model_config of `APIErrorResponseSchema`.

I'd like to globally specify multiple different _named_ examples as possible via the OpenAPI examples (see https://fastapi.tiangolo.com/tutorial/schema-extra-example/#body-with-multiple-examples). Globally, because I'd like to reuse the specified additional responses across multiple routers.

How can I achieve this, when these additional responses are provided via the `responses` key on the router itself?

Additionally, is it possible to extend these examples specified on the router for a single path operation? E.g. for a single path of a router, the 500 code should have another example.

## Accepted answer by YuriiMotov (MEMBER)

When you specify examples in the `json_schema_extra` of model, they are placed inside `schema` of response object. And seems that Swagger can't interpret multiple examples from response object schema.

As an alternative, you can provide examples outside of response object schema (as an `examples` field of [response media type object](https://spec.openapis.org/oas/v3.1.0.html#media-type-object)):

```python
from fastapi import APIRouter, FastAPI
from pydantic import BaseModel


class ErrorSchema(BaseModel):
    error_type: str
    message: str
    detail: str | None = None


class APIErrorResponseSchema(BaseModel):
    error: ErrorSchema


router = APIRouter(
    responses={
        500: {
            "model": APIErrorResponseSchema,
            "description": "Internal Server Error",
            "content": {
                "application/json": {
                    "examples": {
                        "example 1": {
                            "value": {
                                "error": {
                                    "error_type": "database_connection_error",
                                    "message": "Database could not be accessed",
                                    "detail": "Database query timed out"
                                }
                            }
                        },
                        "example 2": {
                            "value": {
                                "error": {
                                    "error_type": "database_connection_error 2",
                                    "message": "Database could not be accessed 2",
                                    "detail": "Database query timed out 2"
                                }
                            }
                        }

                    }
                }
            },
        },
    }
)

@router.post("/here")
async def post_here():
    pass


app = FastAPI()

app.include_router(router=router)

```

This way Swagger interprets them correctly
