### Description

Using a path parameter with simple type union, I can not see if there is any way to flag one of the types as deprecated.

This is a valid api definition in openapi spec that I am attempting to replicate purely with FastAPI.

```
          "schema": {
            "oneOf": [
              {
                "type": "string",
                "title": "Code",
              },
              {
                "type": "string",
                "format": "uuid",
                "title": "ID",
                "deprecated": true,              }
            ],
          },
          "name": "uuid_or_str",
          "in": "path"
        }
```

FastAPI generates the following schema:
```
            "schema": {
              "anyOf": [
                {
                  "type": "string",
                  "format": "uuid"
                },
                {
                  "type": "string"
                }
              ],
```

Is there a way to flag the UUID as deprecated, or a way to override the generated schema for a simple type union to manually specify the deprecated flag?

## Accepted answer by JavierSanchezCastro (CONTRIBUTOR)

You can do something like:

```python3
from fastapi import FastAPI, Path
from uuid import UUID
from typing import Annotated
from pydantic import WithJsonSchema

DeprecatedUUID = Annotated[UUID, WithJsonSchema({"type": "string", "format": "uuid", "deprecated": True})]

app = FastAPI()


@app.get("/{value}")
def fetch(value: Annotated[DeprecatedUUID | str, Path(description="A UUID or a string")]):
    return {"hello": "world"}
```

But this just works on `/redoc`, so I think this is not FastAPI side
