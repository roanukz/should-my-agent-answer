## Accepted answer by ArmanShirzad (NONE)

### Fix

 Your happy-path test is the only one that needs startup state. Since `TestClient(app)` is created without a context manager, the lifespan startup does not run, templates are not loaded, and your handler likely returns 404 for “template not found.” Use a context-managed client so startup runs, and align your model keys.

---

#### Minimal fix: run lifespan in tests

```python
# conftest.py or test_main.py
import pytest
from fastapi.testclient import TestClient
from app.main import app

@pytest.fixture(scope="module")
def client():
    # This triggers lifespan startup and shutdown
    with TestClient(app) as c:
        yield c
```

Update tests to use the fixture:

```python
def test_valid_method(client, good_test):
    resp = client.post("/template1/", json=good_test)
    assert resp.status_code == 200
    assert resp.headers["Content-Type"] == "application/json"
```

---

#### Make the failure obvious

```python
def test_root(client):
    r = client.get("/")
    data = r.json()
    assert r.status_code == 200
    # Ensure templates actually loaded during tests
    assert len(data.get("loaded_templates", [])) > 0
```

---

#### Key gotchas to clean up

* **Model vs payload keys**
  Your model shows `table: List[Table1]` but tests send `table1`. Your route also checks `payload.table1`. Pick one name and use it everywhere. Example:

  ```python
  class Template1Payload(BaseModel):
      docId: str
      salutation: str
      firstName: str
      familyName: str
      table1: list[Table1]   # align with tests
  ```

  And in the handler:

  ```python
  if not payload.table1:
      raise HTTPException(status_code=400, detail="Table 1 missing")
  ```

* **Correct runner guard**
  In `main.py` change

  ```python
  if name == "main":
  ```

  to

  ```python
  if __name__ == "__main__":
      import uvicorn
      uvicorn.run(app, host="127.0.0.1", port=80, log_level="info")
  ```

* **Trailing slash**
  You mounted `router = APIRouter(prefix="/template1")` and `@router.post("/")`.
  Your test uses `"/template1/"`, which is correct. Keep them consistent.

---

#### Optional: speed up unit tests with mocks

```python
from unittest.mock import patch

@patch("app.templates.get_all", return_value={"template1": "<html>...</html>"})
@patch("app.pdf.generate_pdf", return_value=b"%PDF-1.4 ...")
def test_valid_method(mock_pdf, mock_templates, client, good_test):
    r = client.post("/template1/", json=good_test)
    assert r.status_code == 200
```

---

#### Why other tests pass

* Missing or bad payloads fail at Pydantic validation or your early checks, so they never touch the template store.
* Only the happy path needs loaded templates, which are empty if startup never ran, so you get a 404.
