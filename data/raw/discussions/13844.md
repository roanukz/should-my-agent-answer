### Description

Hi, I'm trying to use websocket to connect the fastapi app with react. In React, if I put the WebSocket creation code outside of useEffect, it works (but I don't want to do that in production because a new socket gets created every render). But if I put the WebSocket logic inside useEffect, the onopen log is never called. 

When WebSocket is created outside of useEffect, I can see the fast api log a connection, but when created inside useEffect, the fast api logs show no new connection.

I then tried replacing my url with a random ws server like "wss://ws.ifelse.io" and this connects fine both in and outside of useEffect. 

Is FastAPI's connection somehow unique ? Could any fastapi expert or React expert give me some advice / ideas ? Thanks

## Accepted answer by eric369java (NONE)

@luzzodev  Hi, I figured it out. I had to use "ws://localhost:8000" as the address instead of "ws://0.0.0.0:8000". The fast api server says listening on '0.0.0.0:8000' so I wrongly assumed that was the address. Thanks for giving it a try.
