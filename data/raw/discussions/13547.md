### Description

In one of my route, I need to import and use a library that's not compatible with uvloop due to how it handles event loops.

I want to serve the rest of the routes with `uvicorn`, and that incompatible route with another ASGI server like `daphne`, to achieve overall higher performance while still making the route usable. Is it possible to do that?

## Accepted answer by yauhen-sobaleu (NONE)

No, it is not possible.

Either 

1) use multi-main application and run these as separate services and use reverse proxy to seamlessly route requests

```python
# app_uvicorn.py
from fastapi import FastAPI

app_uvicorn = FastAPI()

@app_uvicorn.get("/")
async def root():
    return {"message": "Hello, FastAPI!"}

# app_daphne.py
from fastapi import FastAPI

app_daphne = FastAPI()

@app_daphne.get("/ping")
async def ping():
    import library_thats_not_compatible_with_uvloop
    return {"message": "pong"}
```

```
uvicorn app_uvicorn:app_uvicorn --host 0.0.0.0 --port 8000
daphne -b 0.0.0.0 -p 8001 app_daphne:app_daphne
```

2) or disable uvloop altogether to be able to use a single server?
```python
import uvicorn

if __name__ == "__main__":
    uvicorn.run("app:app", host="0.0.0.0", port=8000, loop="asyncio")
```
