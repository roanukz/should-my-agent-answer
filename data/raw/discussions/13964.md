### Description

Hi all,

I want to be able to create a pydantic model for my query parameters as described here: https://fastapi.tiangolo.com/tutorial/query-param-models/
This works as described and I get my query parameters parsed into my model as in `annotated_query` and `default_arg_query`. I want to combine this with [dependency injection](https://fastapi.tiangolo.com/tutorial/dependencies/). However I don't see a straightforward way to do this. Using dependency injection by itself allows the request to be processed as expected, however the automatic docs no longer recognize the model fields as query parameters. I tried to combine both `Query` and `Depends` as in `annotated_depends_default_arg_query`, however the automatic docs generation did not recognize the model fields as parameters. Is there anyway to use both dependency injection along with specifying a model as a query parameter model?

## Accepted answer by YuriiMotov (MEMBER)

There is one hacky way. It's based on the fact that if you declare 2 endpoints with the same path, FastAPI will use first of them to handle requests, but second will be used for schema generation.
Not sure if this is a bug or feature.

Not sure you will find any other solution.

```py
from typing import Annotated

from fastapi import Depends, FastAPI, Query, Request
from pydantic import BaseModel, ValidationInfo, model_validator

app = FastAPI()


class ParamModel(BaseModel):
    a: int
    url: str | None = None

    @model_validator(mode="after")
    def some_validator(self, info: ValidationInfo):
        if isinstance(info.context, dict) and (request := info.context.get("context")):
            # do something with context...
            self.url = str(request.url)
        return self


def parse_params(request: Request):
    print("Validate with context...")
    return ParamModel.model_validate(request.query_params, context={"context": request})



@app.get("/my_path")
async def annotated_depends(request: Request, param: Annotated[ParamModel, Depends(parse_params)]):
    """
    Will validate with context using dependency injection
    """
    return param


@app.get("/my_path")
async def annotated_query(request: Request, param: Annotated[ParamModel, Query()]):
    pass  # This is just for docs
```
