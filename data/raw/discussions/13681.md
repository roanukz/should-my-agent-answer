### Example Code

```python
from fastapi import FastAPI, Header
from pydantic import BaseModel, BeforeValidator
from typing import Annotated


def split_to_list(value):
    print(value)
    if isinstance(value, str):
        return value.split(",")
    return value


class Headers(BaseModel):
    x_fruits: Annotated[list[str], BeforeValidator(split_to_list)]


app = FastAPI()


@app.get("/")
def bug(headers: Annotated[Headers, Header()]):
    return headers
```


### Description

* Open the browser and go to the swagger docs
* Call the "/" endpoint after setting the x-fruits header with multiple items
* Observe that it appears as a list with a single item inside the function used by Pydantic's BeforeValidator. I expect it to get the raw header value (string).
* Use case: I want to keep the items separately in the list

## Accepted answer by luzzodev (CONTRIBUTOR)

As far as you annotate your field as `list` or friends( `tuple`, `set`, etc) you will always receive as input a `list[str]` (explode: true → format 2)
If you want to support only type 1 you should declare your field as `str` and not `list[str]` and something like the one proposed by @JavierSanchezCastro but in a computed field.
Tecnically the solution from Javier could be simplified since mixing type 1 and 2 should not be allowed.
If you really want to support only type 1 you can do something like that

```python
app = FastAPI()

async def x_fruits_headers(
        x_fruits: Annotated[str, Header(json_schema_extra={"type": "array", "items": {"type": "string"}})]
) -> list[str]:
    return x_fruits.split(",")

@app.get("/")
def bug(rq: Request, x_fruit: Annotated[list[str], Depends(x_fruits_headers)]):
    return x_fruit
```

But this want work inside a BaseModel since there are still some problems with HeadersModel
