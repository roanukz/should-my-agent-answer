### Example Code

This works:

``` python
# Dependency function
async def get_token_header(test: str = Header(..., example="test-123")):
    return test


# Use Depends in route
@app.get("/debug")
async def read_items(test: str = Depends(get_token_header)):
    return test
```

But this does not work:
``` python
# Dependency function
async def get_token_header(Authorization: str = Header(..., example="test-123")):
    return Authorization


# Use Depends in route
@app.get("/debug")
async def read_items(Authorization: str = Depends(get_token_header)):
    return Authorization
```

It results in the response:
```
{
  "detail": [
    {
      "type": "missing",
      "loc": [
        "header",
        "Authorization"
      ],
      "msg": "Field required",
      "input": null
    }
  ]
}
```

### Description

When trying to use the header named `Authorization` it is ignored. However other header names like `test` work fine.
