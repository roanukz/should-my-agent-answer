## Accepted answer by YuriiMotov (MEMBER)

We can't relax the requirements to always use the latest version of Starlette, because Starlette may introduce breaking changes any time and this can break FastAPI.

So, we need to bump Starlette dependency manually, carefully checking that it doesn't brake FastAPI and projects built with FastAPI.
These checks take some time, so we will often be a little bit behind the latest Starlette release.

By this moment FastAPI supports the latest version of Starlette.

@Houbein, could you please describe why it's such a big problem for you? Do you have other dependency that strictly depends on the latest version of Starlette?
