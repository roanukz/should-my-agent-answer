### Example Code

```python
from fastapi import FastAPI, Query, Depends
from typing import Annotated
from pydantic import BaseModel

app = FastAPI()

class Old(BaseModel):
    old_username: str = "old"
    old_phone: str | None = None

class New(BaseModel):
    new_username: str = "new"
    new_phone: str | None = None

@app.get("/params_query")
async def params_query(
    query_new: Annotated[New, Query()],
    query_single: Annotated[int | None, Query()] = None,
    query_old: Old = Depends(),
):
    return {
        "query_new": query_new,
        "query_single": query_single,
        "query_old": query_old,
    }
```


### Description

When using Annotated[Model, Query()] as a query parameter, FastAPI fails to recognize it if there is also a single query parameter (e.g., int | None) in the same handler. However, using Depends() instead of Annotated[Model, Query()] works fine.And using both two schema style query parameter,it also works fine.

## Accepted answer by YuriiMotov (MEMBER)

This is a known limitation. For now combining Query model with single parameters or combining several Query models in one path operation is not supported
