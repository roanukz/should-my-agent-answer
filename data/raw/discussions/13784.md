## Accepted answer by Damon0603 (NONE)

Hi, 
I think fastapi run is fine for production. If you look in your installed modules -> .venv/lib/python3.12/site-packages/fastapi_cli/cli.py . You can see fastapi run command is essentially a smart wrapper around uvicorn that:
- Auto-detects your FastAPI app
- Handles module imports automatically
- Provides nice formatting and logging
 
But still exposes most of the important uvicorn options including --workers etc, which you of course would need in a prod setup. 


Cheers :)
