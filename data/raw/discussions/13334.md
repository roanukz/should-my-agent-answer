# Doubts about "async def" in the document

Discussion #13334 · 2025-02-08T06:03:02Z · https://github.com/fastapi/fastapi/discussions/13334

## Question

Is this sentence correct in this document(https://fastapi.tiangolo.com/async/#in-a-hurry)? I think this should be **normal def**, not **async def**. If the application does not need to wait, there is no need to be asynchronous.

![image](https://github.com/user-attachments/assets/0b27fdd8-89e0-4b5d-af54-5a5e12242fdf)

## Accepted answer by jgould22 (NONE)

It is correct though perhaps not super clear if you do not have a great understanding of async/sync.

Async IO at the OS level is still "new" or not offered depending on the OS you are using as such for new people just trying to learn quickly this is telling you if you need to do any IO and your database library for example does not offer an async interface then use def.

If you route does not have to do any further IO (talk to a database, make an http request etc), for example it just adds two numbers together and returns them you should use async.
