## Accepted answer by tiangolo (MEMBER)

Thank for the report @davidbrochart and everyone here. :coffee: 

Would this work for you all? https://github.com/fastapi/fastapi/pull/15785

For example:

```python
from fastapi.routing import iter_route_contexts

for route_context in iter_route_contexts(router.routes):
    print(route_context.path)
```

Check the tests in the PR, they show the equivalent use cases.

It would be great to get feedback before merging and releasing.
