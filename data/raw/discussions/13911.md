## Accepted answer by YuriiMotov (MEMBER)

FastAPI doesn't support multiple query models. You need to combine them into one model.
One approach is using multiple inheritance:
```python
class QueryParameters(FilterSet, Ordering):
    pass

@app.get("/")
async def index(params: QueryParameters = Query()):
    query = select(User)
    query = params.filter_queryset(query)
    query = params.order_queryset(query)
    # request database
```
