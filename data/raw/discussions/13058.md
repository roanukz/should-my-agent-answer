## Accepted answer by luzzodev (CONTRIBUTOR)

There is an error in your example, you should type the request input but you declaring two different inputs.
```
# Wrong
def post_form(request, Request, form: t.Annotated[forms.StudentForm, Form()]): 

# Corrected
def post_form(request: Request, form: t.Annotated[forms.StudentForm, Form()]):
```

``` python
app_a = FastAPI()
@app_a.post("/form")
def post_form(request: Request, form: t.Annotated[forms.StudentForm, Form()]):
    return {
        "name": form.name,
        "degree": form.degree,
    }
```
