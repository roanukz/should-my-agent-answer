### Description

## Accepted answer by YuriiMotov (MEMBER)

When you run app as `fastapi run test.py --root-path /api/v1`, it's supposed that you run it behind the proxy that strips prefix.
If not, Uvicorn adds the prefix second time and your app gets `http://127.0.0.1:8000/api/v1/api/v1/docs`.

So, you should configure proxy as shown in docs: https://fastapi.tiangolo.com/advanced/behind-a-proxy/#testing-locally-with-traefik
