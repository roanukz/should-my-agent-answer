## Accepted answer by YuriiMotov (MEMBER)

This is because
```
def read_root() -> None:
```

is equal to
```
def read_root():
```
(if you don't specify return value type, it's `None` by default)

In addition to what @XiaoXinYo suggested, you can use `Literal[None]`:
```
from typing import Literal
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root() -> Literal[None]:
    return None
```
