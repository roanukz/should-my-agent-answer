### Description

  modified to return hardcoded JSON objects or raise exceptions. Changes to the Python files were not being reflected
  when testing the API, and 422 validation errors were not being triggered for invalid request bodies.

## Accepted answer by YuriiMotov (MEMBER)

> ERROR: [Errno 10048] error while attempting to bind on address ('127.0.0.1', 8000): only one usage of each socket address (protocol/network address/port) is normally permitted

This means you have second server running on the same port.
Try restarting your system or killing the process
