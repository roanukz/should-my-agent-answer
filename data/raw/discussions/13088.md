## Accepted answer by YuriiMotov (MEMBER)

Found [related question](https://github.com/fastapi/fastapi/discussions/9709#discussioncomment-6252433) and it's advised there to use `RootModel` to force creating external schema (component):

So, changing this:
```
TSCleaningStepImputationDiscriminated = Annotated[
    TSCleaningStepImputation, Body(discriminator="method")
]
...
TSCleaningStepsDiscriminated = Annotated[TSCleaningSteps, Field(discriminator="kind")]

```
to this:

```
TSCleaningStepImputationDiscriminated = RootModel[Annotated[
    TSCleaningStepImputation, Body(discriminator="method")
]]
...
TSCleaningStepsDiscriminated = RootModel[Annotated[TSCleaningSteps, Field(discriminator="kind")]]

```

seems to be working
