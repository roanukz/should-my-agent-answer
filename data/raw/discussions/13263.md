### Example Code

```python
from fastapi import FastAPI
from pydantic import BaseModel

class Bar(BaseModel):
    a: str
    z: str
    b: str
    
    model_config = {
        "json_schema_extra": {
            "examples": [
                {
                    "a": "x",
                    "z": "x",
                    "b": "x",
                }
            ]
        }
    }

app = FastAPI()

@app.get("/foo")
async def foo() -> Bar:
    return Bar(a="x", z="x", b="x")
```


### Description

The swagger documentation automatically sorts schema keys alphabetically.

I have seen this behavior on the pydantic documentation :
https://docs.pydantic.dev/latest/concepts/json_schema/#json-schema-sorting

However, FastAPI generates the documentation itself, by automatically discovering the schemas. How do I tell it not to sort the schema keys to respect the order of the keys defined in my schema which respects what I provided in the "json_schema_extra" key.

## Accepted answer by valentinDruzhinin (CONTRIBUTOR)

Try to use string instead of dict. In that case it preserves the order:
```
from fastapi import FastAPI
from pydantic import BaseModel

class Bar(BaseModel):
    a: str
    z: str
    b: str
    
    model_config = {
        "json_schema_extra": {
            "example": """{
                "a": "x",
                "z": "x",
                "b": "x"
            }"""
            
        }
    }

app = FastAPI()

@app.get("/foo")
async def foo() -> Bar:
    return Bar(a="x", z="x", b="x")

```
