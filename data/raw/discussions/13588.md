### Example Code

```python
import uvicorn
from pydantic import BaseModel
from tortoise.models import Model
from tortoise import fields
from fastapi import FastAPI

app=FastAPI()


class Student(BaseModel):
    name: str
    
    class Config:
        from_attributes = False


class StudentORM(Model):
    name = fields.CharField(max_length=255)



@app.get("/",response_model=Student)
async def get():
    so = StudentORM(name="tt")
    return so
    
if __name__ == '__main__':
    uvicorn.run('test3:app', host='127.0.0.1', port=8081,reload=True,workers=1)
```


### Description

In a FastAPI application, I have set `from_attributes` to `False`. My GET route returns a Tortoise ORM instance, and I have configured the `response_model` to be a Pydantic model class. The fields of the ORM instance and the Pydantic model class are consistent, and I did not encounter any errors when requesting this route. I would like to know if this behavior is unrelated to the value of `from_attributes`, or if there is some internal conversion taking place?
