### Description

Hi there!

I'm trying to test conditional registering of a startup event (conditional because once it is registered this event requires some CPU resources throughout the process lifespan, and I want to be able to control that).

I'm unable to find how to check what startup events have been registered.
I tried the above (`app.router.on_startup`), and I thoroughly searched the internet, FastAPI's codebase, and Starlette's codebase (for the Lifespan context manager), and I wasn't able to find an accessor that allows to get which events have been registered.
I most likely missed something somewhere, but after searching for an hour, I figured it would be better to ask here.

Anyone knows how to/if it is possible to check startup events that have been subscribed on the app?

## Accepted answer by p-hebert (NONE)

Found the source of the issue! It was simply a typo in the env var in the tests 🤦‍♂️ 
This being said, I followed your advice and migrated to the lifespan approach:

`app/main.py`
```python
# app/main.py

from contextlib import asynccontextmanager
from fastapi import FastAPI
from app.lifespan import some_lifespan_ctx

@asynccontextmanager
async def lifespan(app: FastAPI):
    async with some_lifespan_ctx():
        yield

app = FastAPI(lifespan=lifespan)
```

`app/lifespan.py`
```python
import asyncio
import os
from contextlib import asynccontextmanager

counter = [0]  # use list because int is immutable and imported by value, not ref

@asynccontextmanager
async def some_lifespan_ctx():
    task = None
    if os.getenv("ACTIVATE_SOME_LIFESPAN_CTX") in ("true", "1"):
        async def poll():
            while True:
                global counter
                counter[0] += 1
                await asyncio.sleep(60)
        task = asyncio.create_task(poll())

    try:
        yield
    finally:
        if task is not None:
            task.cancel()
            try:
                await task
            except asyncio.CancelledError:
                pass
```

`tests/test_lifespan.py`
```python
import asyncio
import pytest
from app.lifespan import counter, some_lifespan_ctx

# Use pytest-asyncio for async tests.

@pytest.mark.asyncio
async def test_lifespan_ctx_no_poll(monkeypatch):
    """
    should not start a polling task when ACTIVATE_SOME_LIFESPAN_CTX is not set to true or 1.
    """
    # arrange: set polling env var to "0" so no polling task is started.
    monkeypatch.setenv("ACTIVATE_SOME_LIFESPAN_CTX", "0")

    async def fake_sleep(duration):
        raise asyncio.CancelledError()  # kill the loop after one iteration

    monkeypatch.setattr(asyncio, "sleep", fake_sleep)

    # act: run the context manager.
    async with some_lifespan_ctx():
        pass

    # assert: since env var is not in (true, 1), the poll loop shouldn't have run.
    assert counter[0] == 0


@pytest.mark.asyncio
async def test_jwks_poller_ctx_with_poll(monkeypatch):
    """
    should start a polling task when ACTIVATE_SOME_LIFESPAN_CTX is set to true or 1.
    """
    # arrange: set polling env var to "1" so polling task is started.
    monkeypatch.setenv("ACTIVATE_SOME_LIFESPAN_CTX", "1")

    async def fake_sleep(duration):
        raise asyncio.CancelledError()  # kill the loop after one iteration

    monkeypatch.setattr(asyncio, "sleep", fake_sleep)

    # act: run the context manager.
    async with some_lifespan_ctx():
        pass

    # assert: since we raise in sleep, counter should be 1
    assert counter[0] == 1
```

and the tests pass! I haven't tested this simplified version per say, but the real use case has been tested and works :))
