### Example Code

```python
import asyncio
from fastapi import FastAPI
from fastapi.responses import StreamingResponse
import uvicorn

app = FastAPI()

async def event_generator():
    """Generate server-sent events."""
    try:
        count = 0
        while True:
            count += 1
            # SSE format: "data: <message>\n\n"
            yield f"data: Message {count} from server\n\n"
            await asyncio.sleep(1)  # Send a message every second
    finally:
        print("Event generator closed (before await)")
        await asyncio.sleep(0)
        print("Event generator closed (after await)")

@app.get("/sse")
async def sse():
    return StreamingResponse(
        event_generator(),
        media_type="text/event-stream",
        headers={
            "Cache-Control": "no-cache",
            "Connection": "keep-alive",
        }
    )


if __name__ == "__main__":
    uvicorn.run(app, host="0.0.0.0", port=8002)
```


### Description

If I make a call to `/sse` and then cancel it while it's streaming, I expect the code inside finally block to execute. What I'm observing is, it executes until it finds any `await` and then it stalls there. In the above case, I can see the first print in the console but not the second.

Interestingly, it works fine in case of a normal GET API. Sounds like it's something related to asynchronous generator? How should I perform asynchronous cleanups then?

## Accepted answer by YuriiMotov (MEMBER)

`StreamingResponse` is actually just re-imported by FastAPI from Starlette.

And this behavior can be reproduced with Starlette app.
So, this should be reported there: https://github.com/Kludex/starlette

```py
import asyncio

from starlette.applications import Starlette
from starlette.responses import StreamingResponse
from starlette.routing import Route


async def event_generator():
    """Generate server-sent events."""
    try:
        count = 0
        while True:
            count += 1
            yield f"data: Message {count} from server\n\n"
            await asyncio.sleep(1)  # Send a message every second
    finally:
        print("Event generator closed (before await)")
        await asyncio.sleep(0)
        print("Event generator closed (after await)")


def sse(request):
    return StreamingResponse(event_generator(), media_type="text/html")


routes = [
    Route("/sse", sse),
]

app = Starlette(debug=True, routes=routes)

```
