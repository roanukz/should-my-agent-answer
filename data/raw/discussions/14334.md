## Accepted answer by JavierSanchezCastro (CONTRIBUTOR)

As I saw, `jsonable_encoder()` calls `asdict()` for `@dataclass`, doing it separately still not working, so I think thats not FastAPI side, but let's see someone else opinion.

Test:
```python3
from pydantic import Field
from pydantic.dataclasses import dataclass
from dataclasses import asdict

@dataclass
class Item:
    name: str
    price: float
    description: str | None = Field(
        default=None, description="The description of the item"
    )
    tax: float | None = Field(
        default=None, description="The tax applied to the item"
    )
    excluded_field: str | None = Field(default=None, exclude=True)
    excluded_if_field: str | None = Field(
        default=None, exclude_if=lambda v: v is None
    )

item1 = Item(
    name="Sample Item",
    description="This is a sample item",
    price=10.5,
    tax=1.5,
    excluded_field="This field is excluded",
    excluded_if_field=None
)

item2 = Item(
    name="Another Item",
    description=None,
    price=20.0,
    tax=2.0,
    excluded_field="This field is excluded",
    excluded_if_field="This field is included"
)

item1_dict = asdict(item1)
item2_dict = asdict(item2)
import dataclasses
print(dataclasses.is_dataclass(item1))
print(dataclasses.is_dataclass(item2))
print(f"{item1_dict=}")
print(f"{item2_dict=}")
```
Output:
> item1_dict={'name': 'Sample Item', 'price': 10.5, 'description': 'This is a sample item', 'tax': 1.5, 'excluded_field': 'This field is excluded', 'excluded_if_field': None}
item2_dict={'name': 'Another Item', 'price': 20.0, 'description': None, 'tax': 2.0, 'excluded_field': 'This field is excluded', 'excluded_if_field': 'This field is included'}
