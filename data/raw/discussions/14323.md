### Example Code

```python
from typing import Annotated
from fastapi import FastAPI, Depends
from fastapi.openapi.utils import get_openapi

app = FastAPI()

def get_random():
    return 4

Random = Depends(get_random)

@app.get("/")
def show_random(r: Annotated[int, Random] | None):
    return {"r": r}


get_openapi(
    title="Test",
    version="1",
    routes=app.routes
)
```

Hello @bfontaine, 

can you try the following?

```python
from typing import Annotated
from fastapi import FastAPI, Depends
from fastapi.openapi.utils import get_openapi

app = FastAPI()

def get_random():
    return 4

Random = Depends(get_random)

@app.get("/")
def show_random(r: Annotated[int | None, Random]):  # Place all types inside Annotated
    return {"r": r}


get_openapi(
    title="Test",
    version="1",
    routes=app.routes
)
```

I do not rember exactly when and if it ever worked with mixed typing annotation.
