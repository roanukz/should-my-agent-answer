## Accepted answer by ceb10n (CONTRIBUTOR)

Hello @fersarr 

The release notes are correct. Before 0.112.0 uvicorn would be installed with `pip install fastapi`:

```shell
pip install fastapi==0.111.1
Collecting...

pip freeze

....
starlette==0.37.2
typer==0.21.1
typing-inspection==0.4.2
typing_extensions==4.15.0
uvicorn==0.40.0
...
```

but you're right, for 0.110.3, pip freeze will show:

```shell
annotated-types==0.7.0
anyio==4.12.1
fastapi==0.110.3
idna==3.11
pydantic==2.12.5
pydantic_core==2.41.5
starlette==0.37.2
typing-inspection==0.4.2
typing_extensions==4.15.0
```

That's because it was introduced in [0.111.0](https://fastapi.tiangolo.com/release-notes/#01110).
