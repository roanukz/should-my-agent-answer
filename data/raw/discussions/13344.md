### Description

If an exception raised during StreamingResponse generator, and the database session has been passed to generator and queried data, the sqlalchemy session won't be correctly closed and garbage collection doesn't work

After started the demo fastapi app (remember to change the database connection and query code), try request it with the following code:
```
with requests.get(
    url="http://127.0.0.1:8080",
    stream=True,
) as response:
    for chunk in response.iter_content(chunk_size=1024):
        if chunk: 
            print(chunk)
```

 Server will raise exception soon after the 2nd response. After the exception raising, if you exit the fastapi service you will got the following warning:

```
The garbage collector is trying to clean up non-checked-in connection <AdaptedConnection <psycopg.AsyncConnection [INTRANS] (host=127.0.0.1 user=api_node_1 database=triplenty) at 0x11989d910>>, which will be dropped, as it cannot be safely terminated.  Please ensure that SQLAlchemy pooled connections are returned to the pool explicitly, either by calling ``close()`` or by using appropriate context managers to manage their lifecycle.
sys:1: SAWarning: The garbage collector is trying to clean up non-checked-in connection <AdaptedConnection <psycopg.AsyncConnection [INTRANS] (host=127.0.0.1 user=api_node_1 database=triplenty) at 0x11989d910>>, which will be dropped, as it cannot be safely terminated.  Please ensure that SQLAlchemy pooled connections are returned to the pool explicitly, either by calling ``close()`` or by using appropriate context managers to manage their lifecycle.
```

## Accepted answer by YuriiMotov (MEMBER)

Can't reproduce the error you mentioned.

But in general, don't use the results of dependencies with yield in `StreamingResponse` generators. Session created this way will be closed right after returning from the endpoint function.

```python
async def get_async_db():
    try:
        async with async_session() as db:
            print("db session created")
            yield db
    finally:
        print("db session closed")

# generator for StreamingResponse
async def mock_generator(db: AsyncSession):
    await asyncio.sleep(1)
    print("attempting to use db session")
    user = await db.scalar(select(User).filter(User.id == 1)) # replace it with your own database query
    yield user.name


@app.get("/", response_class=StreamingResponse)
async def end_pint(
    db: AsyncSession = Depends(get_async_db),
):
    return StreamingResponse(content=mock_generator(db=db))

```

Output (attempt to use closed session):
```
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
db session created
db session closed
INFO:     127.0.0.1:58070 - "GET / HTTP/1.1" 200 OK
attempting to use db session
```

Instead, pass session maker to it and open session inside:

```python
import uvicorn
import asyncio
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy.ext.asyncio import async_sessionmaker
from sqlalchemy.ext.asyncio import create_async_engine
from sqlalchemy import Column, Integer, String, select
from fastapi import FastAPI
from fastapi import Depends
from fastapi.responses import StreamingResponse
from sqlalchemy.orm import DeclarativeBase

class Base(DeclarativeBase):
    pass

class User(Base):
    __tablename__ = "user"
    id = Column(Integer, primary_key=True, index=True)
    name = Column(String(50), index=True)

# database connection
async_engine = create_async_engine(
    "sqlite+aiosqlite://"
)
async_session = async_sessionmaker(autocommit=False, bind=async_engine)


async def lifespan(app: FastAPI):
    async with async_engine.begin() as conn:
        await conn.run_sync(Base.metadata.create_all)
    async with async_session() as session:
        async with session.begin():
            user = User(name="test")
            session.add(user)
    await session.commit()
    yield
    await async_engine.dispose()

app = FastAPI(lifespan=lifespan)


async def get_async_db():
    async with async_session() as db:
        yield db

async def get_async_db_sessionmaker():
    return async_session

# generator for StreamingResponse
async def mock_generator(db_sessionmaker: async_sessionmaker):
    await asyncio.sleep(1)
    db: AsyncSession
    async with db_sessionmaker() as db:
        user = await db.scalar(select(User).filter(User.id == 1))
    yield user.name
    await asyncio.sleep(1)
    raise Exception("mock exception")


@app.get("/", response_class=StreamingResponse)
async def end_pint(
    db_sessionmaker: async_sessionmaker = Depends(get_async_db_sessionmaker),
):
    return StreamingResponse(content=mock_generator(db_sessionmaker=db_sessionmaker))

```
