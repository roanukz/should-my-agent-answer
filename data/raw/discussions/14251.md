### Example Code

```python
from fastapi import APIRouter

router = APIRouter(prefix='/api')

router.include_router(router) # Locks program
```


### Description

Passing a router's own object into the `include_router` method results in FastAPI locking up, requiring the Python process to be terminated.

This should be resolved by checking `if router is self: ...` and then raising some error. This is preferred to the current implementation because currently type checkers will not raise any flags and may require some tedious debugging.
