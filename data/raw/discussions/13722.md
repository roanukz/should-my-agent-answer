## Accepted answer by YuriiMotov (MEMBER)

Yes, it seems that this new syntax is not fully supported yet.
For now, you can use old syntax for type aliases (`D: typing.TypeAlias = dict[int, int]`):

```python
import json
from typing import TypeAlias

from fastapi import FastAPI

app = FastAPI()

D: TypeAlias = dict[int, int]

@app.post("")
def a(c: D):
    pass

print(json.dumps(app.openapi()["paths"][""]["post"], indent=4))
```

**Issue to track this:** https://github.com/fastapi/fastapi/issues/10719
