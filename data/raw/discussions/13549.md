### Example Code

class ProactorServer(uvicorn.Server):
    def run(self, sockets=None):
        loop = ProactorEventLoop()
        asyncio.set_event_loop(loop)  # since this is the default in Python 3.10, explicit selection can also be omitted

if __name__ == '__main__':

## Accepted answer by yauhen-sobaleu (NONE)

It seems that `ProactorEventLoop` doesn't work well with Uvicorn's reload functionality on Windows.

Instead of subclassing `uvicorn.Server`, modify your code and try to use the `WindowsSelectorEventLoopPolicy` explicitly when running with reload:

```python
import asyncio
import uvicorn
from fastapi import FastAPI

asyncio.set_event_loop_policy(asyncio.WindowsSelectorEventLoopPolicy())

app = FastAPI()

if __name__ == '__main__':
    uvicorn.run("your_app:app", host="0.0.0.0", port=8000, reload=True)
```
