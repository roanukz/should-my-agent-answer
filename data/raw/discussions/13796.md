# FastAPI needs more core maintainers

Discussion #13796 · 2025-06-17T03:12:17Z · https://github.com/fastapi/fastapi/discussions/13796

## Question

FastAPI is currently the most popular asynchronous Python web framework, which is great, and it has a very large community of users.

However, at the moment, we can't help but feel concerned. FastAPI hasn't released a new version for a long time, and the recent updates have mostly been documentation-related (community translations).

I envy communities like Django and Flask. I have mixed feelings about benevolent dictator for life.

Pydantic and Astral-sh are both excellent teams. Even though they've founded companies, they haven't abandoned their open-source projects. They continue to actively maintain them and release more amazing projects.

FastAPI, including other projects under the organization, is currently in an unmaintained state. We don't dare to use them in production environments because when issues arise, they are almost impossible to fix.

FastAPI is working on other great things:

https://x.com/tiangolo/status/1933504685505175923

We look forward to these great projects, but we need the fundamentals to be ensured.  

We hope FastAPI will get better and better, but for now, it doesn’t seem to be the case.

## Accepted answer by tiangolo (MEMBER)

Thanks for the interest and concern!

We are currently reviewing and mapping discussions and PRs to find related things that should be handled together, etc. You probably have seen all the work @YuriiMotov is doing. Also @alejsdev has been helping manage PRs for a while.

And we have structured plans for each one of the projects that we need to tackle in the right order for them to have the biggest impact.

Meanwhile, is there any feature or issue that concerns you in particular? Is there something that is not working well for you already and makes you worry? It would be best to give a thumbs up to that issue or PR, which would help us see it.

Also, if you want to help accelerate things, there are many ways to help, for example, answering discussions, or helping review PRs: https://fastapi.tiangolo.com/help-fastapi/#help-others-with-questions-in-github
