### Example Code

```python
from typing import Annotated

from fastapi import FastAPI, Query
from pydantic import AliasChoices, BaseModel, ConfigDict, Field

app = FastAPI()


class QueryParams(BaseModel):
    model_config = ConfigDict(validate_by_name=True, validate_by_alias=True)
    my_field = Field(alias="myFieldAlias", validation_alias=AliasChoices("myFieldAlias", "my_field"))


@app.get("/")
def test(query_params: Annotated[QueryParams, Query()]):
    return query_params
```


### Description

I would expect the validate_by_name and validate_by_alias features from Pydantic's Field to work as expected when parsing Query parameters.

For example, using the alias works
```
curl "http://localhost:8000/?myFieldAlias=abc"
```

But using the field name results in a validation error, despite validate_by_name being true.
```
curl "http://localhost:8000/?my_field=abc"
```

Further, if one just instantiates Pydantic instances in code, both of the following work as expected
```
QueryParams(my_field="abc")
QueryParams(myFieldAlias="abc")
```

## Accepted answer by YuriiMotov (MEMBER)

OpenAPI spec doesn't support specifying alternative names for request parameters, so I think this is unlikely to be supported by FastAPI (this will create inconsistency between actual validation and the openapi schema).

For now you can only declare one name for each request parameter (either name or alias).
But there is an issue here as well: to specify the alias you need to use `Query` instead of `Field`:

```py
class QueryParams(BaseModel):
    my_field: str = Query(alias="myFieldAlias")
```

Full code in details:

<details>

```py
from typing import Annotated

from fastapi import FastAPI, Query
from fastapi.testclient import TestClient
from pydantic import BaseModel

app = FastAPI()

class QueryParams(BaseModel):
    my_field: str = Query(alias="myFieldAlias")

@app.get("/")
def get_(query_params: Annotated[QueryParams, Query()]):
    return query_params

client = TestClient(app)

def test_alias():
    response = client.get("/", params={"myFieldAlias": "test"})
    assert response.status_code == 200, response.text
    assert response.json() == {"my_field": "test"}

def test_openapi_schema():
    openapi_schema = app.openapi()
    assert (
        openapi_schema["paths"]["/"]["get"]["parameters"][0]["name"] == "myFieldAlias"
    )
```

</details>
