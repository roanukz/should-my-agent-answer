## Accepted answer by luzzodev (CONTRIBUTOR)

Hello @xuchen, it looks like you’re using a fairly old version of FastAPI.
 This issue was fixed here: [https://github.com/fastapi/fastapi/pull/9700](https://github.com/fastapi/fastapi/pull/9700) by pinning Redoc to version 2.

For anyone using FastAPI below `0.115.13`, please follow this section of the docs to redefine the ReDoc endpoint with a pinned version:
[https://fastapi.tiangolo.com/how-to/custom-docs-ui-assets/#custom-cdn-for-javascript-and-css](https://fastapi.tiangolo.com/how-to/custom-docs-ui-assets/#custom-cdn-for-javascript-and-css).

Fastapi from version `0.115.13` is using the following as default redoc_js_url: 
```
https://cdn.jsdelivr.net/npm/redoc@2/bundles/redoc.standalone.js
```

Thanks for your submission.
