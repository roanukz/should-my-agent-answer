## Accepted answer by sehraramiz (NONE)

This example is working for me, ```/protected/docs``` showing swagger with auth option and ```/not-protected/docs``` not showing auth options.

```python
from fastapi import FastAPI, Depends
from fastapi.security import OAuth2PasswordBearer
from pydantic import BaseModel


class Data(BaseModel):
    x: str


async def protected_method(d: Data):
    pass


async def not_protected_method(d: Data):
    pass


swagger_protect = OAuth2PasswordBearer(tokenUrl="/token")


def get_not_protected_end_points() -> FastAPI:
    result = FastAPI()

    result.add_api_route(
        path="/test", endpoint=not_protected_method
    )
    return result


def get_protected_end_points() -> FastAPI:
    result = FastAPI(dependencies=[Depends(swagger_protect)])

    result.add_api_route(
        path="/test", endpoint=protected_method, dependencies=[Depends(swagger_protect)]
    )
    return result


app = FastAPI()

app.mount(path="/protected", app=get_protected_end_points())
app.mount(path="/not-protected", app=get_not_protected_end_points())

```

**i am not hosting the swagger assets locally.**
