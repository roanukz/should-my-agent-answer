### Example Code

```python
from typing import Annotated

import fastapi
import pydantic


class Inputs1(pydantic.BaseModel):
    a1: str
    a2: str


class Inputs2(pydantic.BaseModel):
    a1: str
    a3: str


router = fastapi.APIRouter()


@router.get("/")
def index(qs: Annotated[Inputs1 | Inputs2, fastapi.Query()]) -> None:
    pass
```
