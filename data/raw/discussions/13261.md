### Example Code

```python
from fastapi import FastAPI
from fastapi.responses import JSONResponse
from pydantic import BaseModel

class A(BaseModel):
    authorid: int
    fileid: int

class B(BaseModel):
    authorid: int

app = FastAPI()

@app.get("/", response_class=JSONResponse, response_model=B)
def read_root():
    return JSONResponse(A(authorid=1, fileid=2).model_dump())

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app)
```

## Accepted answer by YuriiMotov (MEMBER)

I think the reason of confusion is this phrase

> But you can also declare the Response that you want to be used

"also" here is a synonym of "as an alternative to previous approach", or "instead of returning instance of `Response` directly".
