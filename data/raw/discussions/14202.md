### Example Code

```python
"""Demonstrates BeforeValidator regression in FastAPI 0.118.2"""
import dataclasses
from typing import Annotated, Optional
from fastapi import FastAPI
from pydantic import BeforeValidator, PlainSerializer
from starlette.testclient import TestClient


# Custom class (similar to MongoDB ObjectId, Version objects, etc.)
@dataclasses.dataclass(frozen=True)
class StudyVersion:
    """Represents a study version like '8.8' or '880'"""
    major: int
    minor: int
    patch: int = 0

    @classmethod
    def parse(cls, value):
        if value is None:
            return None
        if isinstance(value, StudyVersion):
            return value
        # Parse "8.8" format
        if isinstance(value, str) and "." in value:
            parts = value.split(".")
            return cls(int(parts[0]), int(parts[1]) if len(parts) > 1 else 0)
        # Parse 880 -> (8, 8, 0)
        value_int = int(value)
        return cls(value_int // 100, (value_int % 100) // 10, value_int % 10)

    def __str__(self):
        return f"{self.major}.{self.minor}" if self.minor else f"{self.major}"


# Type definition (common pattern in production code)
StudyVersionStr = Annotated[
    StudyVersion,
    BeforeValidator(StudyVersion.parse),
    PlainSerializer(str)
]

app = FastAPI()


@app.post("/studies", response_model=None)
def create_study(name: str, version: Optional[StudyVersionStr] = None):
    """
    In 0.118.1: version is correctly parsed to StudyVersion instance
    In 0.118.2: version stays None, BeforeValidator is not called
    """
    print(f"version parameter: {version!r}")
    return {
        "name": name,
        "version": str(version) if version else None,
    }


if __name__ == "__main__":
    import fastapi
    print(f"Testing with FastAPI {fastapi.__version__}")

    client = TestClient(app)
    response = client.post("/studies?name=test&version=8.8")
    print(f"Response: {response.json()}")

    # Expected in 0.118.1:
    #   version parameter: StudyVersion(major=8, minor=8, patch=0)
    #   Response: {'name': 'test', 'version': '8.8'}  ✅

    # Actual in 0.118.2:
    #   version parameter: None
    #   Response: {'name': 'test', 'version': None}  ❌
```


### Description

## Description

  In FastAPI **0.118.1**, `BeforeValidator` works correctly with `Optional[Annotated[T, BeforeValidator(...)]]` query parameters:
  - Query parameter `?version=8.8` is parsed to `StudyVersion(major=8, minor=8, patch=0)` ✅
  - The validator function is called as expected

  In FastAPI **0.118.2**, the same code **silently breaks**:
  - Query parameter `?version=8.8` is ignored, endpoint receives `version=None` ❌
  - `BeforeValidator` is **not called at all**
  - No error raised at startup, validation is completely bypassed

  ### Root cause

  This regression appears to be introduced by **PR #12942** ("Fix tagged discriminated union not recognized as body field").

  While the PR correctly fixes discriminated unions, it inadvertently breaks `BeforeValidator` execution for query parameters with `Annotated` types.

  ### Impact

  This is a **silent regression** affecting production code:
  - Custom version objects (e.g., StudyVersion)
  - Custom ID types with parsing logic
  - Any domain-specific value objects using `BeforeValidator`

  The application starts without errors, but validation logic is completely bypassed and endpoints receive `None` instead of validated objects.

## Accepted answer by YuriiMotov (MEMBER)

Since your actual type (`StudyVersion`) is complex, FastAPI treats it as `Body` parameter, but you send it as `Query`, that's why it's `None`.
For me it's more strange that it worked before 0.118.2. 

So, it looks like it worked because of the bug, and that bug was fixed by https://github.com/fastapi/fastapi/pull/12942.

For simple types it works as expected:
```py
from typing import Annotated, Optional
from fastapi import FastAPI
from pydantic import BeforeValidator
from starlette.testclient import TestClient

MyAnnotatedType = Annotated[str, BeforeValidator(lambda x: f"p_{x}")]

app = FastAPI()

@app.post("/")
def post_(param: Optional[MyAnnotatedType] = None):
    return {"param": param}

def test_():
    client = TestClient(app)
    response = client.post("/", params={"param": "value"})
    assert response.status_code == 200, response.text
    assert response.json() == {"param": "p_value"}
```
