### Example Code

```python
import time
from fastapi import FastAPI, BackgroundTasks

async def waitInLine( seconds=2, bg:BackgroundTasks=None):
    print(f"Stopping for {seconds} seconds")
    time.sleep(seconds)
    print(f"Done")


app = FastAPI( debug=True )

@app.get('/test/bg')
async def test_background_tasks( background_tasks: BackgroundTasks ):
    background_tasks.add_task( waitInLine, 8)
    return {"message": "Running a task in the background"}
```


### Description

1. Call the URL on a browser

On Windows, and running in dev mode (with `fastapi dev`), the response is sent right now, while the background task runs.

## Accepted answer by YuriiMotov (MEMBER)

If you need to execute blocking code inside the `async` function, use `await run_in_threadpool()`:
```diff
async def waitInLine( seconds=2, bg:BackgroundTasks=None):
    print(f"Stopping for {seconds} seconds")
-    time.sleep(seconds)
+    await run_in_threadpool(time.sleep, seconds)
    print(f"Done")
```

Or, make you background task function sync (if you don't need to use `async` functions inside it):
```diff
- async def waitInLine( seconds=2, bg:BackgroundTasks=None):
+ def waitInLine( seconds=2, bg:BackgroundTasks=None):
    print(f"Stopping for {seconds} seconds")
    time.sleep(seconds)
    print(f"Done")
```
