### Description

The key thing of this is i want this tier checking function ignore the tier checking if user's role is admin or higher, but since the token location were different between user and admin, i've no idea about this.

## Accepted answer by valentinDruzhinin (CONTRIBUTOR)

Try to treat both logins as the same `Bearer token` at request time and pick whichever token is present. Then your min_tier just depends on the unified `current user` dependency.
Try to use the example like that:
```
from typing import Annotated, Optional
from fastapi import Depends, HTTPException, Security, status
from fastapi.security import OAuth2PasswordBearer

user_oauth2 = OAuth2PasswordBearer(
    tokenUrl="/api/auth/token", scheme_name="user", auto_error=False
)
admin_oauth2 = OAuth2PasswordBearer(
    tokenUrl="/api/auth/admin/token", scheme_name="admin", auto_error=False
)

async def get_current_user(
    user_token: Annotated[Optional[str], Security(user_oauth2)],
    admin_token: Annotated[Optional[str], Security(admin_oauth2)],
    db: AsyncSession = Depends(get_db),
    flow: UserAuthenticateFlow = Depends(get_user_auth_flow),
) -> User:
    token = admin_token or user_token
    if not token:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED, detail="Not authenticated"
        )
    # Your flow should decode the token and return the User (role/tier in claims/DB)
    return await flow(db=db, token=token, with_sub=False)

def min_tier(required: Tier):
    async def checker(user: User = Depends(get_current_user)):
        # bypass if admin (adjust roles as you use them)
        if getattr(user, "role", None) in {Role.admin, Role.superadmin}:
            return user

        if TIER_LEVEL[user.tier] < TIER_LEVEL[required]:
            raise HTTPException(
                status_code=status.HTTP_403_FORBIDDEN,
                detail=f"Insufficient tier. Required at least {required}",
            )
        return user
    return checker

@router.get("/extract_map", dependencies=[Security(user_oauth2), Security(admin_oauth2)])
async def extract_map(_: User = Depends(min_tier(Tier.Mid))):
    return {"message": "Hey I'm premium feature"}
```
