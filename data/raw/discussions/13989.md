### Description

Deta Space hosting for FastAPI no longer works because Deta has shut down its free hosting service.
The current FastAPI deployment documentation still mentions Deta (for example: https://fastapi.xiniushu.com/ko/deployment/deta/) and includes CLI install commands:

- iwr https://get.deta.dev/cli.ps1 -useb | iex

- curl -fsSL https://get.deta.dev/cli.sh | sh

These commands now fail because the domain get.deta.dev no longer resolves.
