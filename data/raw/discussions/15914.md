### Example Code

```python
"""Pure public API: N threads issue the app's FIRST requests concurrently,
each through its own TestClient (own event loop per thread). All requests
return 200 here, but the interleaved unlocked rebuilds leave the included
router's cached candidate list with far more than len(routes) entries —
permanently — and corrupt the global warnings filters. The same unlocked
window can also 404 valid routes (deterministic script in the description).
"""
import threading
import warnings

import fastapi
from fastapi import APIRouter, FastAPI
from starlette.testclient import TestClient

N_ROUTES = 120
N_THREADS = 6


def build_app() -> FastAPI:
    app = FastAPI()
    router = APIRouter()
    for i in range(N_ROUTES):
        def endpoint(q: int = 0, _i: int = i):
            return {"i": _i, "q": q}

        router.add_api_route(f"/r{i}", endpoint, methods=["GET"])
    app.include_router(router)
    return app


def main() -> int:
    print(f"fastapi {fastapi.__version__}")
    filters_before = len(warnings.filters)

    app = build_app()
    barrier = threading.Barrier(N_THREADS)
    statuses = []

    def worker() -> None:
        client = TestClient(app)
        barrier.wait()
        statuses.append(client.get(f"/r{N_ROUTES - 1}").status_code)

    threads = [threading.Thread(target=worker) for _ in range(N_THREADS)]
    for t in threads:
        t.start()
    for t in threads:
        t.join()

    from fastapi.routing import _IncludedRouter

    included = next(r for r in app.router.routes if isinstance(r, _IncludedRouter))
    cache_len = len(included._effective_candidates)
    print(f"statuses: {statuses}")
    print(f"cached candidates: {cache_len} (expected {N_ROUTES})")
    if len(warnings.filters) != filters_before:
        print(f"warnings.filters leaked: {filters_before} -> {len(warnings.filters)}")
    return 1 if cache_len != N_ROUTES else 0


if __name__ == "__main__":
    import sys

    sys.exit(main())
```


### Description

Since the router-inclusion refactor in 0.137.0 (#15745), `_IncludedRouter.effective_candidates()` and `effective_low_priority_routes()` (`fastapi/routing.py`) rebuild their cached candidate lists lazily on first request with no synchronization:

```python
routes_version = self.original_router._get_routes_version()
if routes_version == self._effective_candidates_version:   # (1) check
    return self._effective_candidates
self._effective_candidates = []                            # (2) wipe: publishes an EMPTY list on the shared attribute
...                                                        # (3) incremental self._effective_candidates.append(...)
self._effective_candidates_version = routes_version        # (4) stamp
```

(`fastapi/routing.py:1583-1602` in 0.139.0; identical on current `master`.)

When more than one thread drives the same app object — e.g. a test suite whose worker threads each own a `TestClient` against one shared app, or any multi-loop/threaded embedding — the app's first concurrent requests race this rebuild. Three observable failures:

**1. Spurious 404 on a valid route.** A thread preempted between (1) and (2) that resumes after another thread completed (4) wipes a version-stamped cache. Until the wiper's own rebuild re-appends the tail routes, every request passes the check (1), iterates a half-built list, gets `Match.NONE`, and falls through to `Router.default` (`await self.default(scope, receive, send)`, `routing.py:2730`) → bare `404 {'detail': 'Not Found'}` for a perfectly valid path/method. We first noticed exactly this as intermittent 404s on an app's first requests in a real project's test suite (per-thread `TestClient`s against one shared app).

**2. Permanent candidate-cache corruption — the Example Code above; reproduces essentially every run.** Concurrent rebuilds interleave their `append`s into the same last-assigned list, so the cache ends up with up to `N_threads x N_routes` entries. Typical output:

```
fastapi 0.139.0
statuses: [200, 200, 200, 200, 200, 200]
cached candidates: 283 (expected 120)
warnings.filters leaked: 5 -> 6
```

(Observed 5/5 runs corrupted, counts varying with interleaving: 283, 166, 226, 247, 375.) Every subsequent request then iterates the duplicated candidates for the lifetime of the app.

**3. Global warnings-filter corruption.** The rebuild constructs pydantic `TypeAdapter`s per route inside `warnings.catch_warnings()` (`fastapi/_compat/v2.py`, `ModelField.__post_init__`). `catch_warnings` mutates process-global state, so concurrent enter/exit corrupts `warnings.filters` — leaked filter entries (see output above) and `UnsupportedFieldAttributeWarning` escaping to stderr.

### Deterministic reproduction of the 404

The 404 needs a specific preemption: between (1) and (2), across another thread's (4). This script forces exactly that schedule by pausing the first rebuilder at two *legal* preemption points with a `threading.settrace` hook — FastAPI code and behavior are untouched; the hook only makes an OS-schedulable interleaving reproducible. Three requests to the same valid route:

```python
import inspect
import sys
import threading

import fastapi
import fastapi.routing as fastapi_routing
from fastapi import APIRouter, FastAPI
from starlette.testclient import TestClient

N_ROUTES = 120


def build_app() -> FastAPI:
    app = FastAPI()
    router = APIRouter()
    for i in range(N_ROUTES):
        def endpoint(q: int = 0, _i: int = i):
            return {"i": _i, "q": q}

        router.add_api_route(f"/r{i}", endpoint, methods=["GET"])
    app.include_router(router)
    return app


def find_lines() -> tuple:
    func = fastapi_routing._IncludedRouter.effective_candidates
    lines, start = inspect.getsourcelines(func)
    wipe = append = None
    for i, line in enumerate(lines):
        if "_effective_candidates = []" in line:
            wipe = start + i
        if "_effective_candidates.append(route_context)" in line:
            append = start + i
    if wipe is None or append is None:
        raise AssertionError("lines not found - fastapi internals changed?")
    return func.__code__, wipe, append


CODE, WIPE_LINE, APPEND_LINE = find_lines()
victim_parked = threading.Event()       # victim sits between check (1) and wipe (2)
victim_release = threading.Event()
victim_mid_rebuild = threading.Event()  # victim wiped + appended <=1 entry
victim_finish = threading.Event()
_parked_once = False
_parked_mid = False
_victim_ident = None


def install_schedule_points() -> None:
    """Two legal preemption points for the FIRST thread that rebuilds (the
    'victim'; both apply to that same thread only). The ASGI app runs on anyio
    portal threads spawned by each TestClient, so we key on 'first arriver'."""

    def local_trace(frame, event, arg):
        global _parked_once, _parked_mid, _victim_ident
        if event == "line":
            if frame.f_lineno == WIPE_LINE and not _parked_once:
                _parked_once = True
                _victim_ident = threading.get_ident()
                victim_parked.set()
                victim_release.wait()   # P1: parked exactly between (1) and (2)
            elif (
                frame.f_lineno == APPEND_LINE
                and threading.get_ident() == _victim_ident
                and not _parked_mid
            ):
                _parked_mid = True
                victim_mid_rebuild.set()
                victim_finish.wait()    # P2: wiped, list nearly empty
        return local_trace

    def global_trace(frame, event, arg):
        if frame.f_code is CODE:
            return local_trace
        return None

    threading.settrace(global_trace)


def main() -> int:
    print(f"fastapi {fastapi.__version__}, python {sys.version.split()[0]}")
    app = build_app()
    target = f"/r{N_ROUTES - 1}"  # a perfectly valid route
    statuses = {}

    install_schedule_points()

    def request(name: str) -> None:
        client = TestClient(app)  # own event loop per thread
        r = client.get(target)
        statuses[name] = (r.status_code, r.json())

    victim = threading.Thread(target=request, args=("victim",), name="victim")
    victim.start()
    assert victim_parked.wait(timeout=30), "victim never reached the wipe line"

    # While the victim sits between (1) and (2): a normal request fully
    # builds the cache and stamps the version.
    warmer = threading.Thread(target=request, args=("warmer",), name="warmer")
    warmer.start()
    warmer.join()
    included = next(
        r for r in app.router.routes
        if isinstance(r, fastapi_routing._IncludedRouter)
    )
    assert statuses["warmer"][0] == 200, statuses["warmer"]
    assert included._effective_candidates_version is not None, "cache not stamped"
    assert len(included._effective_candidates) == N_ROUTES

    # Release the victim: its very next bytecode wipes the stamped cache.
    # It is paused again (P2) right at the first append of its rebuild loop.
    victim_release.set()
    assert victim_mid_rebuild.wait(timeout=30), "victim never reached the append line"
    assert len(included._effective_candidates) <= 1, "wipe did not land as scheduled"
    assert included._effective_candidates_version is not None  # version still stamped!

    # A third, completely ordinary request: version check passes, list is
    # half-built -> falls through to Router.default -> 404.
    reader = threading.Thread(target=request, args=("reader",), name="reader")
    reader.start()
    reader.join()

    victim_finish.set()
    victim.join()

    for name in ("warmer", "victim", "reader"):
        print(f"{name:>7}: {statuses[name]}")

    ok = (
        statuses["warmer"][0] == 200
        and statuses["victim"][0] == 200
        and statuses["reader"][0] == 404
    )
    if ok:
        print(f"\nBUG REPRODUCED: valid route {target} returned 404 after the "
              "version-stamped candidate cache was wiped by a concurrently "
              "rebuilding thread.")
        return 1
    print("\nschedule did not produce the 404 (unexpected)")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

Under plain concurrent load the same window is hit stochastically (CPU load increases the rate); the Example Code shows the underlying interleaving happens essentially every time, so hitting the 404 in the wild is a matter of scheduling luck, not of whether the race exists.

### Who is exposed

A single-event-loop server (typical uvicorn worker) matches routes on one thread, so it does not contend on the rebuild. Exposed are setups where one app object is driven from multiple threads/loops: parallel test suites with per-thread `TestClient`s, threaded/multi-loop embeddings, apps shared across loops.

### Suggested fix

Build into a local list and publish only when complete, stamping after publishing; concurrent rebuilds then become redundant but harmless:

```python
def effective_candidates(self):
    routes_version = self.original_router._get_routes_version()
    if routes_version == self._effective_candidates_version:
        return self._effective_candidates
    candidates: list[_EffectiveRouteContext | _IncludedRouter] = []
    for route in self.original_router.routes:
        ...  # append to the local `candidates`
    self._effective_candidates = candidates
    self._effective_candidates_version = routes_version
    return candidates
```

Same pattern for `effective_low_priority_routes()`. A `threading.Lock` would also close the window and additionally serialize the redundant rebuild work; the local-build variant relies on CPython attribute-store atomicity, so free-threaded builds may still want the lock. Note that the `warnings.catch_warnings()` usage in `ModelField.__post_init__` stays inherently thread-unsafe whenever model fields are built at request time — even with the rebuild race fixed, two loops building adapters concurrently can still corrupt the global filters; that may deserve a separate look.
