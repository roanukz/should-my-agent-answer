## Accepted answer by YuriiMotov (MEMBER)

Usual (non-streaming) response classes expect you pass the content to it.

But sometimes the content could be too big to load it into memory (imagine you need to return the content of 10Gb video file).
In such cases you may want to send response by chunks in order not to hit memory limit.

To do so, you need to create a [async generator function](https://docs.python.org/3/glossary.html#term-asynchronous-generator) that will read one chunk of the file at a time and yield it. Then, attach this generator function to `StreamingResponse` object and return this object from your endpoint.

FastAPI will call your generator function iteratively and send chunks of the file to client one by one.
