# Bug with complex fields (`list[str]`) inside `BaseModel`

Discussion #14889 · 2026-02-10T14:47:36Z · https://github.com/fastapi/fastapi/discussions/14889

## Question

### Privileged issue

- [x] I'm @tiangolo or he asked me directly to create an issue here.

### Issue Content

## Summary
When "complex" (e.g., `list[str]`) field is definied inside `BaseModel`, it doesn't get parsed.

## MRE1
### Summary
Example when "complex" field defined in `BaseModel` doesn't get parsed.

#### Code
```python
from typing import Annotated
import uvicorn
from fastapi import Depends, FastAPI, Query
from pydantic import BaseModel

class MyParams(BaseModel):
    size: Annotated[int | None, Query()] = None
    field: Annotated[list[str] | None, Query()] = None

app = FastAPI()

@app.get("/items")
async def get_items(
    params: Annotated[MyParams, Depends()],
) -> None:
    print("params: ", params)

if __name__ == "__main__":
    uvicorn.run(app, host="127.0.0.1", port=8000)
```

#### Request:
```bash
curl --location 'localhost:8000/items?size=100&field=foo&field=bar'
```

#### Expected:
```text
params:  size=100 field=foo,bar
INFO:     127.0.0.1:54972 - "GET /items?size=100&field=foo&field=bar HTTP/1.1" 200 OK
```

#### Actual:
```text
params:  size=100 field=None
INFO:     127.0.0.1:54972 - "GET /items?size=100&field=foo&field=bar HTTP/1.1" 200 OK
```

## MRE2
### Summary
Example when "complex" field is moved from `BaseModel` to a separate attribute and gets parsed.

#### Code
```python
from typing import Annotated
import uvicorn
from fastapi import Depends, FastAPI, Query
from pydantic import BaseModel

class MyParams(BaseModel):
    size: Annotated[int | None, Query()] = None

app = FastAPI()

@app.get("/items")
async def get_items(
    params: Annotated[MyParams, Depends()],
    field: Annotated[list[str] | None, Query()] = None,
) -> None:
    print("params: ", params)
    print("field: ", field)

if __name__ == "__main__":
    uvicorn.run(app, host="127.0.0.1", port=8000)
```

#### Request:
```bash
curl --location 'localhost:8000/items?size=100&field=foo&field=bar'
```

#### Expected:
```text
params:  size=100
field:  ['foo', 'bar']
INFO:     127.0.0.1:55020 - "GET /items?size=100&field=foo&field=bar HTTP/1.1" 200 OK
```

#### Actual:
```text
params:  size=100
field:  ['foo', 'bar']
INFO:     127.0.0.1:55020 - "GET /items?size=100&field=foo&field=bar HTTP/1.1" 200 OK
```

## Accepted answer by YuriiMotov (MEMBER)

Declaring Query parameters using Pydantic model with `Depends()` was never officially supported.
To declare Query parameters using Pydantic model, use the approach described in docs: https://fastapi.tiangolo.com/tutorial/query-param-models/
