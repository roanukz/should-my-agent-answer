### Example Code

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/app")
def read_main():
    return {"message": "Hello World from main app"}


subapi = FastAPI()


@subapi.get("/sub")
def read_sub():
    return {"message": "Hello World from sub API"}


app.mount("/subapi", subapi)
```


### Description

The OpenAPI paths generated by FastAPI for `subapi` are supposed to be prefixed with the mount path `"/subapi"`, they are not. This causes an incorrect openapi.json to be generated that cannot be used with Swagger UI and does not work as the documentation says: https://fastapi.tiangolo.com/advanced/sub-applications/#sub-application
