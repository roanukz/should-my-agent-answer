### Example Code

```python
from fastapi import FastAPI, WebSocket
from fastapi.exceptions import WebSocketRequestValidationError

app = FastAPI()


@app.websocket("/ws")
async def websocket_endpoint(websocket: WebSocket):
    await websocket.accept()
    # Trigger a WebSocket validation error
    raise WebSocketRequestValidationError(
        [{"loc": ["query", "token"], "msg": "Field required", "type": "missing"}]
    )
```


### Description

When a WebSocket endpoint raises **`WebSocketRequestValidationError`**, FastAPI’s default exception handler attempts to close the connection using **`reason=jsonable_encoder(exc.errors())`**. Since this value is a list/dict and not a string, the underlying WebSocket implementation crashes when it tries to encode the close reason.

Expected behavior:
The server should close the WebSocket cleanly with status code 1008 (Policy Violation) and without crashing.

Actual behavior:
The server raises **`AttributeError: 'list' object has no attribute 'encode'`**, causing an abnormal WebSocket close (1006) and logging a server-side traceback.

This happens with the default FastAPI WebSocket validation exception handling and can be reproduced with a minimal WebSocket endpoint that raises **`WebSocketRequestValidationError`**.

### Steps to Reproduce

1. Create a file `main.py` with the following content:

```python
from fastapi import FastAPI, WebSocket
from fastapi.exceptions import WebSocketRequestValidationError

app = FastAPI()

@app.websocket("/ws")
async def websocket_endpoint(websocket: WebSocket):
    await websocket.accept()
    raise WebSocketRequestValidationError(
        [{"loc": ["query", "token"], "msg": "Field required", "type": "missing"}]
    )
```

2. Install dependencies:

```bash
pip install fastapi uvicorn
```

3. Run the application:

```bash
uvicorn main:app
```

4. Open a browser and navigate to `http://127.0.0.1:8000/`.

5. Open the browser DevTools console and run:

```javascript
const ws = new WebSocket("ws://127.0.0.1:8000/ws");
ws.onopen = () => console.log("opened");
ws.onclose = (e) => console.log("closed:", e.code, e.reason);
ws.onerror = (e) => console.log("error:", e);
```

## Accepted answer by YuriiMotov (MEMBER)

I think `WebSocketRequestValidationError` is intended to be used during the connection stage only (before `await websocket.accept()`).

To indicate an error in input data sent through the opened websocket connection you can raise `WebSocketException`:

```
from fastapi import FastAPI, WebSocket, WebSocketException

app = FastAPI()


@app.websocket("/ws")
async def websocket_endpoint(websocket: WebSocket):
    await websocket.accept()
    # Trigger a WebSocket error
    raise WebSocketException(
        code=1008,
        reason="Custom WebSocket validation error occurred.",
    )
```
