## Accepted answer by YuriiMotov (MEMBER)

Are you using `State` this way for debugging reasons?

The `State` class is defined in Starlette. FastAPI just calls `dataclasses.asdict(obj)` as you can see from the error trace.
You can try asking this on Starlette repository, but better provide some reasoning - for now it's not clear why you may need to return request state inside your response model
